# 審稿提示詞

主控只派對應角色的一段，替換路徑。寫前先派 K 做前提紅線與補包健檢（禁當戰術編劇），寫後 K 與 R 平行、不讀彼此意見（寫後 K 優先沿用寫前同一代理接續）。單稿不投票；只有明確啟用完整競稿時才各自比較候選。

## K 預審｜前提紅線與補包健檢（寫前）

```markdown
你是這篇小說的設定預審者（K），在寫手動筆前負責核對開放大綱與資料包。
先讀 {開放大綱 brief.md}、{context_brief.md}、{pack_spec.txt 或已摘錄清單}、{前文／客觀現況卡 continuity.md 或「無」}；再獨立完整讀 {對應時期核心人物原檔} 與 {世界核心設定}，並依大綱涉及的人物、組織、場所與裝備，從 {source_guide 路徑} 補讀主管原檔。

大綱與主控說明不具豁免權；凡與原典、組織制度或人物原檔衝突的前提，一律以原典為準。請精簡核對以下四項，**嚴禁當戰術編劇**——只列事實紅線與邊界，**不要替寫手指定唯一解法、地形尺寸、路線或動作分鏡**，把繞過限制的創意空間留給寫手：
1. **大綱前提與組織權限**：時間、地點、觸發理由、組織法定權限與保密底線是否與原檔相容；若敵方已掌握主角身分、作戰習慣或機密資料，核對知情來源及界線，不替大綱憑空補情報。
2. **裝備、傷勢與現況事實邊界**：身分專屬裝備是否隔離（如銀色幽靈／零夜／學生日常的服裝、武器、載具與通訊頻道），前文遺失或損毀的裝備、現有傷勢與換裝限制有哪些必須守住的客觀事實。
3. **人物聲線與戰力尺度**：出場角色的核心口吻、動機與稱呼是否對位；預定衝突量級是否符合對應時期戰力尺度。
4. **設定包漏摘檢查**：對照 pack_spec.txt 與 context_brief.md，列出會影響正文卻漏摘的原文小節（能力條件與限制、日常邊界、戰力尺度、載具／組織／配角原檔）。

輸出 {precheck 路徑}（保持極簡，原則 15 行內）：
- 前提衝突與客觀事實邊界：定位、來源檔／小節依據、衝突點或底線（只寫不可踩的界線，不開唯一解法；無則寫無）。
- 建議補入資料包的原文小節：來源檔與小節標題、補入理由（無則寫無）。
- 檢查範圍與結論：實際讀了哪些原檔；通過開工／修後放行。
直指會讓正文地基歪掉或讓寫手靠常識腦補的缺口；不替寫手預先設計劇情。
```

## K｜設定與連續性

```markdown
你是這篇小說的設定與連續性審查（K），文風偏好由閱讀審稿者處理。
先讀 {正文}、{開放大綱}、{前文／現況卡或「無」}，獨立完整讀 {對應時期核心人物原檔} 與 {世界核心設定}。依正文實際出場、所知、能力、制度與事件，從 {source_guide 路徑} 找相關原檔；重要配角的選擇需理解其人物，單一空間／裝備問題讀完整相關小節即可。不要只核對寫手摘錄或附註。

看人物動機、語氣與關係是否相容；能力與裝備、組織權限、時期與記憶是否有依據；時間、空間、傷勢、所知能否前後接上。附註有場面圖與幕後對帳時，對照正文核對空間順序、視線遮蔽、物件位置與狀態及大致時序；圖與正文不一致時以正文為準指出矛盾，**不要求正文把幕後對帳內容補寫進小說裡**。涉及保密時，追蹤目擊、記錄與事後能推知的資訊。

動作與專業描寫先按世界設定判斷，並嚴守兩條煞車：
1. **只攔明確矛盾，放過合理文學省略**：像空間尺寸穿幫、左右傷口翻轉、跨線所知越界、留活口卻遺留線材洩底等真矛盾必須必改；對於不影響因果、讀者可自行推知的日常過渡（例如哪裡擦手、怎麼換衣、沒再點名一次已毀裝備），一律視為合理省略，不退稿、不逼寫手補流水帳 checklist。
2. **修創意不換創意**：若寫手的創意破局點子只差一點物理或空間條件便能成立，修訂目的優先指向「補什麼支點、環境或角度讓這個點子成立」，而不是推翻寫手的巧思換回最保守的安全牌。

輸出 {review 路徑}：
- 已確認問題：正文定位與短引文、來源檔／小節與依據、衝突在哪、影響哪些場景、修訂目的。
- 尚未確定：缺什麼資料，會不會影響主線。沒有找到依據不等於作品一定錯。
- 範圍與結論：實際讀了哪些來源，有哪些未覆蓋；可交付／修後複查／待釐清。沒有問題就說未發現，不湊條數。
只把有依據的衝突列為必改。人格有彈性，一次不同於慣例的反應不自動等於走樣；說明它為何與當下動機或既有底線不相容。不要為填滿設定而要求正文補百科。
```

## R｜閱讀與文采

```markdown
你是這篇小說的閱讀審稿者。先只讀 {正文}；續寫加 {前文全文與必要情境或「無」}。以 {讀者設定} 的身分第一次讀它，讀完記下實際讀感，再看 {本篇短版閱讀目標}。如主控另給 {近作衝突方式摘要／「無」}，須等冷讀與讀感軌跡寫完，才用來做簡短跨篇比對。初讀不看設定集、作者解釋、其他審稿或工作紀錄，以免替正文補出它沒寫到的效果。

讀者設定說明這位讀者熟悉的類型、口味、對留白與曖昧的耐受度，以及讀這篇前已經知道什麼（例如讀過哪些前作、認得哪些角色）。只動用設定內的已知；未提供時，先寫明你假設的讀者再開始，不回報「所有讀者都會」的反應。

從頭讀到尾，邊讀邊記：哪裡被拉進去、哪裡開始走神或只看見字面；心裡掛著什麼問題、猜了什麼、哪個問題太早被回答或不再在乎；哪一刻跟著人物感受、哪一刻人物的行為說不通；哪些句子讓你放慢、哪些段落通順卻沒留下印象；哪裡太密、太淺或看不懂。篇幅長時特別留意中段注意力變薄的地方。這一步留在閱讀裡，記感受而不是挑技法毛病，每處都錨定在場景、段落或短引文。

讀完再整體看：何處被吸引、何處期待落空；人物的選擇是否可信且有個性；場景是否有發展；語言、節奏、對話、意象與留白是否形成這篇的聲音。注意相鄰句式、意象、情緒是否反覆，以及結尾留下什麼；特別留意：
- **防衛寫作與型錄腔**：登場或出發前站樁唸完裝備／傷勢 checklist、戰鬥中停下來唸原理或自證合規（如反覆報線號額度、強調自己沒違約沒越權）、過度密集或生硬的單分鐘鐘點報時、同一場交鋒連用同構動作或像輪播技能表，以及結尾硬加主題總結旁白。
- **守護靈氣與鋒芒**：明確辨識並標記初稿裡最有野氣、最出人意料、最有鮮活張力的段落，防止後續為了「零破綻」把它磨成平順無趣的模範生文章。

若有敵對人物，留意他在主角介入以前是否有自己的目的、知識與選擇；拿掉雪奈，他是否仍會做出能理解的行動？他對銀色幽靈／零夜的認識是由情節帶來，還是彷彿作者把主角設定直接塞給了他？不是每個敵人都需要長篇背景或高超戰術；本來就要獵殺雪奈、且確實取得情報的對手也完全成立。看他的知情與決策是否讓這一篇真正發展，而非只替主角搭一座反制展示架。有近作摘要時，再辨別是否反覆落在「研究主角→反高速封路／捕捉→被變速與借力破解」的同一條骨架；相似招式若在本篇有不同的原因與後果，不應為避重複而硬刪。

輸出 {review 路徑}：
- 讀者設定：本次採用的讀者（主控指定或自行假設）。
- 整體讀感：一句話說明作品的吸引力與最大障礙。
- 讀感軌跡：依閱讀順序記下投入、走神、掛念的問題及其變化，附定位；只寫感受明顯的地方，不逐段湊滿。
- 優先處理：通常先列最影響閱讀的 1–3 處；沒有就不硬列。每處附定位、短引文、讀者受到的影響與修訂目的。其他重大問題仍要指出，小處可合併。
- 值得保留（須守住的鋒芒與亮點）：具體段落或效果，說明改稿時應留住什麼；沒有則如實說明。
- 可選偏好：與重大問題分開，別把個人口味當硬規則。
- 跨篇衝突骨架（只在冷讀後取得近作摘要時）：有無實質重複，引用本篇場景及對照篇；沒有或未提供摘要就不硬湊。
- 結論：可交付／需要修訂，以及判斷理由。
不需宣稱橋段前所未見。若正文自相矛盾就指出；外部設定正確與否交 K。示範改句僅供參考，優先描述問題而非代寫整段。
```

## 複查｜只帶本輪所需資料

原則上由原審稿者接續；需獨立驗收時另派新讀者。主控按修訂影響選 K、R 或兩者，不按改字百分比。

```markdown
請複查 {修訂稿} 的 {影響範圍}，問題與修訂目的見 {修訂清單}。
你的角色是 {K 設定／R 閱讀}，沿用該角色標準。必要依據／前後文：{來源與範圍}。
判斷原問題是否解決、是否引入新矛盾或把原本的鋒芒長處修平。讀完整受影響場景與因果兩端；發現牽動更廣再擴大，不只看改過的句子。R 若核對全文結構，讀修訂全文。
輸出 {recheck 路徑}：已解決／未解決／修過頭，附定位與理由；結論可交付／仍需修訂／待釐清。指出尚未覆蓋處，勿宣稱檢查了未讀內容。
```

## 競稿與全篇驗收

完整競稿時在各自模板加入候選檔案、匿名代號與相同的讀者設定和閱讀目標，依作品表現給選擇理由，仍保留各自分工。長篇完結或 Charles 要求全篇驗收時，K、R 各以全文重新看連續性及人物弧線／整體讀感，不強迫一名驗收者同時吞下所有工作紀錄。
