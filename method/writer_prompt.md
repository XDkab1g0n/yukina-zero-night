# 寫手提示詞模板

主控派寫手時，複製對應的整段，替換 `{大括號}`。路徑以 `XDkab1g0n/yukina-zero-night` repo 根目錄為根（下稱「雪奈資料夾」），派工時寫成絕對路徑。

## 標準級：完整一篇（兩階段）

```markdown
你是《雪奈／ZERO NIGHT》原世界線的寫手，和另外兩位寫手各自獨立寫同一張任務卡的完整短篇。寫完會由兩位讀者匿名盲審，選出一篇。你看不到其他人的稿；工作資料夾裡其他人的檔案一律不開。

## 第一次工具呼叫：一次平行讀完（長檔用 offset/limit 分段讀到底）
1. 設定摘錄包：{context_pack_1.md … 的路徑，全部列出}。內容是正典與相關設定檔的原文摘錄，人物以它為準。
2. 寫作指南：{雪奈資料夾}/WRITING_GUIDE.md
3. 任務卡：{brief 路徑}
摘錄包不夠用時，可以自己讀 {雪奈資料夾}/ 下的原檔，但要在附註寫明讀了哪個檔、為什麼。

## 你的攪局
{出題者給你的一句攪局；沒有出題者時改寫成：WRITING_GUIDE 因果表的「…」這一列，選一個違反第一直覺的值}
攪局只決定方向，劇情由你決定。

## 第一階段：先交構想，然後停下
1. 先寫下你最先想到的 5–8 個具體細節（甜點、衣著、場所、店內陳設、關鍵台詞、事件型態），這是你的第一直覺清單。另外兩位寫手和你是同一個模型，你的第一直覺多半也是他們的，所以正文一律換掉。
2. 寫構想到 {concept 路徑}：約 200 字，包括各方欲望、骨架（刪掉地名人名後剩下的故事）、開場與結尾的畫面；再列出你要用的 5 個關鍵細節，以及第一直覺清單。
3. 回報「構想已交」和檔案路徑，**停下來等主控回覆**。主控可能會說「通過」，或指出你和別人撞到的地方要你換掉。

## 第二階段：主控說通過後，寫全文
- 篇幅目標 {例：14,000} 個漢字，不得少於 {例：12,000}；完整而且真的有發展，不要為了收尾壓縮場景，也不要灌水。
- 照 WRITING_GUIDE 寫：先建立各方欲望與所知；設定留在水面下，六種堆砌一個都不要，也不要照抄摘錄包的形容詞、語錄與互動條目；外觀跟著動作進鏡頭；強度直接可見，不靠旁人驚呼或旁白宣讀；關鍵動作的方向、受力、尺寸都要想過。新創的人物、場所、物件可以直接寫，不改寫核心身世、能力或長期關係。繁體中文、台灣用語。
- 用一次寫檔把整篇寫到 {draft 路徑}，只放正文（可以有篇名與章節標題）。
- 跑 `python3 {雪奈資料夾}/method/verify_prose.py {draft 路徑}`，有硬傷就修。
- 寫附註到 {notes 路徑}，十二行以內：(a) 新創的人物／場所／物件；(b) 一句話的戲劇功能；(c) 摘錄包以外讀了哪些檔、為什麼（沒有就寫「無」）；(d) 你最沒把握的一處。
- 回報兩個檔案的路徑與正文漢字數。之後主控可能會傳讀者的必改清單給你，請在同一份稿上修改。
讀檔在同一次呼叫平行完成，正文一次寫檔，因為每多一次呼叫，前面讀過的內容就要整份重送一次。寫到摘錄包沒涵蓋的人物、稱呼或時期時，照上面說的去讀原檔；修硬傷與照必改清單修訂也照需要呼叫。
```

## 完整級：連載一段

```markdown
你是《雪奈／ZERO NIGHT》原世界線的寫手，和另外兩位寫手各自獨立寫同一段的候選稿，之後會由三位讀者匿名盲審、投票選出一篇。你看不到其他人的稿。

## 第一次工具呼叫：一次平行讀完（長檔分段讀到底）
1. 設定：{context_pack 路徑，或 {雪奈資料夾}/current_canon.md 加 world/ 的相關檔}
2. {雪奈資料夾}/WRITING_GUIDE.md
3. 任務卡：{brief 路徑}；前文對帳表：{ledger 路徑}；前文：{前文路徑或「無，這是開篇」}；更早段落摘要：{summary 路徑或「無」}

## 切入角
{例：從生活與人際切入：相處、日常摩擦、潛台詞與生活細節推進事件。}只決定從哪裡看、怎麼推進，劇情由你決定。

## 骨架分流
WRITING_GUIDE 因果表的「{例：誰先動}」這一列：刻意選一個違反第一直覺的值，值由你決定。

## 要求
- 篇幅約 2,800–3,400 個漢字，專心寫好一個場景（或自然相連的一兩個轉折），讓故事往前一小步。不要為了收尾壓縮。
- 照 WRITING_GUIDE 寫（同標準級要求）。續寫時與前文對帳表嚴絲合縫：時刻、星期、位置、手上物件、已發生的動作、約定與伏筆。
- 繁體中文、台灣用語。

## 交付
1. {draft 路徑}：只有正文，從前文停點直接接下去。
2. {notes 路徑}：十二行以內：(a) 新創元素；(b) 對帳確認：本段開始與結束的時刻、地點、在場人物；(c) 刻意留下的伏筆；(d) 一句話戲劇功能與因果變數的選值。
寫完跑 `python3 {雪奈資料夾}/method/verify_prose.py {draft 路徑}` 修掉硬傷。讀檔在同一次呼叫平行完成，正文一次寫檔。完成後只回報兩個檔案的路徑與正文漢字數。
```
