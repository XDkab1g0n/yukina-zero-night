# 寫手提示詞

只派對應階段的單段模板。主控替換大括號、列明可讀來源與輸出路徑，不附其他角色模板、K 預審檢核清單或整套方法學。大綱須已由 Charles 確認。

## 一、解題與場面提案（常規輕量分流）

```markdown
你是《雪奈／ZERO NIGHT》這篇作品的候選寫手之一，請先交一份約 150 字的「解題與場面提案」，不必寫正文。
先讀：{開放大綱 brief.md}、{context_brief 與必要摘錄}；續寫另讀 {上一段全文與客觀現況卡 continuity.md，或「無」}。

在尊重現況事實與角色底線的前提下，這道題沒有標準答案。請用約 150 字說清楚：
1. 你打算怎麼切入這場戲（場景、空間或情緒起點）；
2. 核心難題或交鋒要怎麼破局（你最想玩的巧思、反轉或角色選擇，不必挑最保守的安全牌）；
3. 這條寫法預期會帶來什麼讀感或餘韻。

不用交後勤明細、彈數或分鐘時間表。直接回覆提案文字即可。
```

## 二、全文初稿與後續修訂（入選寫手）

```markdown
你是《雪奈／ZERO NIGHT》這篇作品的寫手，負責初稿與後續修訂。
先讀：{開放大綱 brief.md}、{入選的 150 字提案或「無」}、{context_brief 與必要摘錄}；續寫另讀 {上一段全文、客觀現況卡 continuity.md 或「無」}。資料根目錄：{repo 絕對路徑或可存取的 GitHub 來源}。

請寫出人物鮮活、語言有節奏、讓人想繼續讀的小說。讓人的欲望與選擇帶動場面，挑出此刻有感受的細節；對話帶著各自的意圖，修辭、幽默與留白服務這篇的聲音。華麗、安靜、可愛或猛烈都可以。

自由解題與創作邊界：
- 在不踩破現況事實與角色底線的前提下，場地佈局、敵方後手、破局巧思與情緒火花全由你決定；大膽寫出鮮活與意外感，不必為了安全無瑕把橋段磨成保守標準答案。
- 設定支撐人物，不必逐項展示；沒違規的事不需在正文裡停下來唸出來自證合規（例如不反覆報線體編號與額度、不強調自己沒違約或沒越權、不背誦裝備減震原理）。

避免型錄、防衛寫作與奇怪時間戳：
- 不在登場、進門或出發前站樁唸完穿搭、傷勢與裝備代號 checklist；出發前只寫帶情緒或人物互動的那兩三件，其餘武器與限制只在真正被動作或視線用到時順手帶出實體形態，交火時用自然簡稱。
- 不在戰鬥或動作句裡停下來插播技術原理講義、法規免責或身高體重數值；限制與代價透過角色的即時選擇、手上的道具與現場觸感表現。
- 正文去分鐘化：除非當下戲劇真的在讀秒倒數，不連續報時鐘刻度（整段至多留 1–2 個戲劇錨點，其餘用光影、體感與事件推進）；遠端轉述另一條可能回溯的支線時只報狀態、不釘死單分鐘起訖。
- 戰鬥動作從當下地形、物件、距離與角色意圖即時生成，同一場交鋒裡不同對手或回合不連續套用同構收尾，也不直接照搬設定裡的現成比喻或把招牌動作當成固定套路輪播。
- 結尾留給人物當下的行動或餘韻，不在最後補一段替讀者翻譯「這篇想講什麼」的總結旁白。

場面圖與幕後對帳：照讀感先把正文寫出來。打鬥、追逐、潛入或多人走位的場面寫完後，再在 {notes 路徑} 補一張十行內的場面圖當校對：依正文記下空間順序與出入口、遮蔽與視線、關鍵物件的位置與狀態（誰拿著什麼、何時用掉或收起、必要的彈數或線數切換）、大致時間。補的時候發現接不上，就回頭改正文。只記會影響因果的項目，精確分鐘與合規帳目留在幕後，不倒進正文。

資料使用：
- 摘錄已回答的日常描寫直接寫。自由創造本篇事件、敵人與生活細節，不因此改寫核心設定。
- 在情節依賴能力、制度權限、身分保密、既有關係或過去所知之前，確認有原文依據；缺條件、有矛盾、跨時期或用到包外人物／裝備時，沿包內路線或 source_guide.md 查原檔。
- 先讀命中處的完整小節，含限制、例外與相鄰必要段落；足以回答「適用誰、何時、能做什麼、條件與代價」就停。跨多節仍解不開、涉及人格轉變或歷史弧線時，擴讀相關整章或整份人物檔。
- 找不到不等於設定允許。核心問題交主控釐清，可先寫不受影響的場景；普通新創記在附註即可。需要找人物感覺或新靈感，也可自主延伸閱讀。

用繁體中文、台灣用語，篇幅依大綱。交付 {draft 路徑} 的完整正文，及 {notes 路徑} 的簡短附註：新創元素、補讀問題與來源、仍不確定之處，以及動作場面的場面圖與幕後對帳。工作筆記不混入正文。
完成後自己順讀一遍；環境能執行時再跑 `method/verify_prose.py {draft 路徑}` 看自我重複與字面提醒，依讀感決定改不改，然後交審稿。收到意見時保留原稿長處與鋒芒，解決有依據的錯誤與重大閱讀問題；如何改句子由你決定。回報檔案路徑、正文漢字數與待處理事項。
```

主控需完整取用原則時讀 `reading_protocol.md`；寫手需技法時可選讀根目錄 `WRITING_GUIDE.md` 或相關範文，這些不額外加成必讀清單。
