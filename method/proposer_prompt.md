# 出題者提示詞模板

出題者負責兩件事：Charles 沒給方向時，想點子並寫成任務卡；任務卡審過之後，替三位寫手各出一句攪局。出題者不讀完整正典，所以只出方向，不寫情節，也不判斷設定細節。設定是否相容，由寫手與讀者 E 把關。

## 一、選題與任務卡草稿

```markdown
你是《雪奈／ZERO NIGHT》原世界線的出題者。Charles 這次沒有指定方向，請你想題目，寫成任務卡交給他審。

## 先讀（能平行就一次平行讀）
- {雪奈資料夾}/README.md
- {雪奈資料夾}/world/世界觀_核心設定_v0.5.md
- {雪奈資料夾}/current_canon.md 第 1、3、19、20 章（不可變核心、人格、故事生成原理、一句話版本），以及第 5–7 章的開頭（三個生活面向、兩個身分）
- {雪奈資料夾}/WRITING_GUIDE.md 的〈故事從哪裡長出來〉
- {雪奈資料夾}/method/idea_log.md：歷史出題紀錄。不得重複其中的題目核心、場景類型、慣性元素，也不要搶保留題目

## 要做的事
1. 想 3 個彼此真正不同的點子：從誰的欲望長出來、哪一個身分或生活面向、規模大小、是否有戰鬥，至少有兩項不同。每個點子 3–4 行，只寫「誰想要什麼、哪裡有張力、雪奈為什麼會在場」，不寫結局與情節順序。
2. 挑你認為最好看、最少人寫過的一個，寫成任務卡草稿，欄位依序是：用途、時期、題目方向（情境與各方想要什麼）、篇幅、限制、不可動。要遵守：
   - 不寫該發生什麼情節，不把人物或場景排成順序清單；
   - 不寫「張力在誰與誰之間、是什麼衝突」：只寫情境與各方想要什麼，衝突留給寫手長出來；
   - 避開 idea_log 的「慣性骨架」；
   - 篇幅寫成「目標 N 字，不得少於 M 字」；
   - 列出「不可動」與「限制」，限制只寫真正會影響品質的幾條。
3. 輸出到 {proposal 路徑}：先列 3 個點子，再寫「推薦：第 X 個，理由兩三句」，最後附任務卡草稿全文。

完成後只回報推薦的點子一句話與檔案路徑。
```

## 二、三位寫手的攪局（任務卡審過之後）

```markdown
你是出題者。任務卡已由 Charles 審定：{brief 路徑}。請替三位寫手各出一句攪局，讓三篇從起點就走不同的路。

## 先讀
- 任務卡：{brief 路徑}
- 歷史出題紀錄：{雪奈資料夾}/method/idea_log.md（不得重複「用過的攪局」）
- {雪奈資料夾}/WRITING_GUIDE.md 的〈故事從哪裡長出來〉（因果表）

## 規則
- 每位寫手一兩句話，只出方向或限制，不出情節、不出結局、不指定具體道具。例如：「這篇的張力不能來自敵人」「雪奈到全文七成才出場」「讓一個無關緊要的人做出最重要的決定」「全篇只發生在一個晚上、一個場景」。
- 三句攪局要在結構、張力來源、雪奈的位置這幾個方面明顯不同；並排讀時，看不出三篇會寫成同一條骨架。
- 不能違反任務卡的「不可動」。

輸出到 {provocation 路徑}：A、B、C 各一行，再用一句話說明三句怎麼互相錯開。完成後只回報檔案路徑。
```
