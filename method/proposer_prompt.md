# 短構想與開放大綱

主控通常自行完成，確實需要獨立探索時才另派出題者。已有指定方向就直接整理開放大綱。只為定案方向準備詳細摘錄。

```markdown
請為《雪奈／ZERO NIGHT》提出 2–3 個短構想。
讀 {本次需求}、{已有的人物核心與世界背景}，參考 {idea_log 最近 3–5 篇}；缺核心卡時依 reading_protocol.md 準備，不把完整工作紀錄當起步資料。

每個構想用一小段說清楚：誰想要什麼、什麼讓這件事有趣、可能形成什麼閱讀感受。讓欲望、選擇或敘事角度有所不同；場景與道具可以重用，避免只是替同一條故事換裝。可以是棘手限制，也可以是好看的碾壓局或日常切磋；不要為了顯得棘手硬湊假危機，也不要把每篇收斂成同款輕喜劇模板。可以提出核心衝突，留給寫手決定具體發展與解法。
構想可以從地下世界的利益衝突、殺手的工作、軍事奇觀、黑暗科幻、荒誕事件、強者的玩興或日常生活出發。冷酷、恐怖、狂放、華麗、黑色幽默與純粹的娛樂性，都可以成為一篇作品的主要閱讀目標。

遇到敵對者時，先想此人在雪奈介入前原本要做什麼、想保住什麼，以及實際知道多少；他的專業、錯判與應對應由自身處境長出來。敵人可以不知道雪奈是誰，也可以合理地研究她；若構想依賴事先針對銀色幽靈／零夜設局，就要有情報來源與設局理由。別為了展示主角速度、變速或反應能力，反向生出一群專門封路、反高速，最後依次被拆解的對手。這是構想檢查，不是禁止精密反制或碾壓局。

推薦一個方向並說明理由，標出會影響成立與否的設定問題。由主控回查關鍵前提後依委託定案。Charles 還在選題時交他決定，明確委託自選並直接交正文時由主控定案。
輸出到 {proposal 路徑}，保持簡短。
```

## 主控整理開放大綱（`brief.md`）

主控用短大綱交代寫手需要的局面與條件。

- 列時期、開局局面、各方欲望、知情及限制、篇幅和 Charles 的必要條件。已有指定收束才固定其結果。另記 R 的一般讀者背景及短版閱讀目標，依 `reader_prompt.md` 分兩輪提供。
- 把場面安排、視角、台詞、局部轉折與破局方式交給寫手。
- 主控回查後把已確認的事實寫入現況，補上必要原文。啟用 K 預審時也以這種方式交接。
- 若有敵對者，記其原本目的、知情邊界與對局面的作用；別把「準備反制雪奈→封鎖速度→被雪奈拆穿」當成預設必經的戰鬥流程。用字數目標說明篇幅，只有 Charles 有最低字數要求才設硬下限。

選題時比較欲望、選擇和敘事角度。同一題有兩種可能導向不同選擇與後果的走法，才依 `LOOP.md` 啟用雙寫手提案。查閱 `idea_log.md` 時保留 Charles 留給自己的題目。
