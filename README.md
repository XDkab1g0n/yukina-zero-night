# 雪奈／ZERO NIGHT 原世界線

這個儲存庫放《雪奈／ZERO NIGHT》原世界線的全部材料：人物正典、各時期與配角設定、寫作指南、多代理寫作流程、範文與正文。**任何 AI 先讀這份 README**，再照下面的表取用檔案。主角是朔夜雪奈；未指定時期時，一律寫十八歲、高三開學後（五月紀念生日之後）的現在篇。

## 專案入口與維護位置

- 唯一持續維護來源：[XDkab1g0n/yukina-zero-night](https://github.com/XDkab1g0n/yukina-zero-night)，分支 `main`，入口為根目錄 `README.md`。
- ChatGPT、Claude 與其他 AI 的專案來源都應指向本儲存庫根目錄；設定權責與多代理寫作流程仍依本 README。
- `workshop/` 為公開工作紀錄，僅保留連載續寫帳本與具代表性的方法學實驗紀錄；`*_PRIVATE.*`（含競稿匿名對照表）、憑證及個人資料不得提交公開儲存庫。

## 依任務讀什麼

| 要做的事 | 起步資料 | 視需要再讀 |

| 寫新故事（主控） | `method/LOOP.md`、`method/reading_protocol.md`、`source_guide.md` | 首次建立人物核心時讀對應時期人物原檔與世界核心設定；依大綱選相關原文 |
| 擔任寫手 | 自己的 `method/writer_prompt.md` 模板、已確認大綱、人物核心與本篇摘錄 | 按包內回查路線補原檔；技法需要時讀 `WRITING_GUIDE.md` 或範文 |
| 寫前傳或回憶 | 同上，但資料包以當期設定與歷史事件索引為來源 | 涉及哪些時期就核對哪些時期，不倒套現在篇 |
| 續寫 | 該篇上一段全文、必要對帳與早期摘要、沿用且已確認版本的本篇資料 | 依新增人物、能力、時期與情節依賴補讀 |
| 沒給方向，要 AI 自己出題 | `method/proposer_prompt.md`、`method/idea_log.md` 的近作與保留題目 | 關鍵假設先核實，大綱交 Charles 確認後才開始正文 |
| 多代理分工 | 主控讀 `method/LOOP.md`；各代理只讀自己的模板與任務資料 | 預設開放大綱＋K 邊界健檢＋雙寫手 150 字解題提案選優＋單寫手初稿＋K／R 平行審稿；完整競稿須明確指定 |
| 設定審查 | `method/reader_prompt.md` 的 K 模板、完整正文、對應時期核心人物原檔與世界核心設定 | 按正文實際使用的設定補查相關原檔，不只核對摘錄 |
| 閱讀審稿 | `method/reader_prompt.md` 的 R 模板、讀者設定、正文與必要前文 | 冷讀後看本篇閱讀目標，保持與設定審查獨立 |
| 設計新配角或對手 | `templates/character_sheet.md`、`WRITING_GUIDE.md`〈設定留在水面下〉 | 相關組織與人物資料 |
| 回答設定問題 | 主管原檔的完整相關小節，不以摘要當證據 | 人格全貌、歷史弧線或跨章關係才擴至整檔 |

**閱讀原則**：摘錄先用，關鍵判斷前按問題回查。完整小節應含條件、例外與必要交叉參照；能回答問題就停，不固定讀幾成。首次建核心卡的整理者與獨立 K 審稿者仍理解完整核心人物；寫手不必重複吞下同樣全文。詳細觸發、停止條件與資料包模板見 `method/reading_protocol.md`。特定作品另有明確全文閱讀要求時依該作品規劃。長檔截斷不算讀完，來源更新要核對受影響摘錄。

## 共同規則

- **原世界線邊界**：本儲存庫僅收錄《雪奈／ZERO NIGHT》原世界線材料，不混入跨作品、平行世界線或外部支線的人物、事件與設定。
- **新創與正典分開**：新故事可以直接創造委託、敵人、場所與傳聞，但不會因此改寫核心身世、能力或長期關係。傳聞、受訪者說法與旁觀者誤解，要和作者採用的設定分清楚。
- **續寫**：接對話中正在寫的那一篇；對話裡沒有，就接 `stories/` 裡開頭標明「連載中」的那一篇（不只一篇或沒有時，先問 Charles 是哪一篇）。從停點沿指定情境接下去，不重新設計設定。
- **交付**：繁體中文、台灣用語。直接交付正文；構思、戰術分析、審稿與工作筆記留在幕後（多代理時放 `workshop/`），Charles 要求才給。要完整一篇或指定篇幅時，交付完整而且真的有發展的作品；高解析度連載不必硬塞結局。
- **存檔**：定稿正文放 `stories/`；在 claude.ai 專案裡寫的稿，也同步一份到這裡，讓兩邊的 AI 都看得到。寫不進 repo 的工作階段先存成專案文件 `雪奈正文/<題目>.md`；下一個能寫入 repo 的工作階段，把它補進 `stories/` 與 `method/idea_log.md`。
