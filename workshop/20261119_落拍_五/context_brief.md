# 資料包導覽：〈落拍〉第五段（雙影返港、三號碼頭截艇與重傷支援反擊）

## 人物核心

- **朔夜雪奈（18 歲｜銀色幽靈）**：
  - 完整自然人（149cm／38kg），世界最高層級全距離射擊與原生神經反應；此刻剛經歷川崎重創縫合（右大腿深層縫合、左小腿毒傷縫合、右 7/8 肋骨骨裂綁胸帶、左下腹舊疤痙攣、右眼輕微腦震盪殘影），信守「不勉強、不硬扛、不爬高不硬落地」承諾，只當奏的支援者，憑緩坡月台與夜巡者平穩磁懸浮、左眼精準點射、極夜短距脈衝與移動駭客托底展現重傷猶強的壓倒實力。
  - **保密偽裝**：散亂銀髮束低塞入診所深色防風外套兜帽，全程戴診所黑色立體醫用口罩不露臉。
- **貓屋敷奏（15 歲｜黑貓）**：
  - 銜尾蛇 S 級控制型殺手，啞黑作戰膠衣＋影縛（三類線互斥、四主兩輔 20m 上限）＋柔術、絕不用槍；開放碼頭＋海風＋自律火力正是其弱點，與雪奈構成經典互補（雪奈清視野／壓火力／解電子，奏封退路／登艇勒暈奪黑盒）。
- **黑岩真希（29 歲｜銜尾蛇委託仲介）**：
  - 銀色幽靈專屬窗口，非戰鬥人員；表面自學關西腔與愛錢口吻，得知雪奈重傷時先褪去營業腔真心想喊停，被說服後轉回護短算帳，透過**銜尾蛇地下情報網與港口私營物流／海事暗網節點**遠端追查（絕不調用官方或八咫烏監控），依《銜尾蛇》假情報違約條款索賠雙倍違約金與裝備賠款；對奏保持適當距離與默契。
- **桔梗靜流（25 歲｜舊城區密醫）**：
  - 開頭把關，於 `00:28` 血漿見底拔針封口、補高純度葡萄糖液、借出寬鬆深色衣褲／防風外套／黑色口罩／防滑平底軟鞋並暫寄氣壓歸零的夢魘舞者，立下樞紐告警即撤紅線。
- **導航員 AI／樞紐**：
  - 啞光黑頸環，與夜巡者整合可作移動通訊中繼與現場駭客平台；盯緊雪奈生命徵象紅線、負責清零敵艇與頭盔視覺紀錄並同步黑盒資料給真希。

## 本篇重點事實

- **時間軸**：`00:25` 診間吹茶 → 真希加密來電與奏說出 `00:40` 三號碼頭快艇（且未拿久世船鑰匙）→ `00:28` 血漿見底拔針 → `00:28–00:31` 換衣、自托盤取回白夜／極夜／夜影與腰帶、暗巷側格補彈並接車載快充、切夜巡者為深藍低調塗層熄燈 → `00:31–00:32` 發車 → `00:38–00:39` 抵三號廢棄碼頭 → `00:40–00:45` 緩坡月台（2.5–3m 高、距船 25–30m，危急時騎車低速滑切至 12–15m）截艇協作奪實體中繼黑盒 → `00:45–00:48` 清零紀錄、同步真希釘死買家集團、並肩返世田谷。
- **戰損與合法裝備**：無斗篷、無紫電、無極光、無夢魘舞者（暫寄診所）、嚴禁動用零夜模式與幻影／鳴神／鎮魂；穿診所備用衣褲＋深色連帽防風外套＋黑色立體口罩＋防滑平底軟鞋；白夜／極夜（側格補實彈＋車載快充極夜短距脈衝電容，12–15m 內有效）、夜影雙匕、樞紐＋低調深藍塗層夜巡者（保留左尾缺飾板、前輪擦痕、右側暗紅血印）。
- **敵方邊界**：跨國財團黑箱回收快艇（標稱無人接應欺瞞五人隊），內建雙聯自律光電哨戒槍塔、三架低空抗風武裝無人機、暗艙兩名直屬半義體收尾員與實體熱熔自毀裝置及電子引信手雷；因無船鑰匙授權與廠區跳閘自動轉入清零警戒，**完全不知銀色幽靈與黑貓身分**。
