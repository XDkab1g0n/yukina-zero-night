# 開放大綱：〈不准停歌〉（LOOP v4 標準流程｜token 基準實測）

- **時期與視角**：十八歲現在篇（高三，五月紀念生日之後），六月梅雨季某個週五深夜。視角由寫手決定（雪奈、小夜或兩者交替皆可）。
- **開局局面**：「迴聲密室」滿場演出夜，S.O.N.Y.A. 正在台上；雪奈以私人身分買票進場當觀眾，沒有接任何委託。健叔顧吧台，暖場團（可用「廢鐵線」）已下台混在觀眾裡。
- **敵方與知情邊界**：一支受雇的回收小隊趁演出闖入，要拿走阿柴留下的黑殼帳本。雇主相信帳本裡夾著阿柴當年替場裡年輕樂手扛下的那件大企業舊事的痕跡（帳本是否真有、有什麼，由本篇決定，不升格正典）。他們知道小夜是能打的地下 DJ／賞金獵人，所以挑她被綁在台上、滿場觀眾可當掩護與籌碼的時段動手；**完全不知道銀色幽靈在場**，也沒有針對她設伏。
- **各方欲望**：小夜要守住場子、帳本與客人，也不容許自己的 set 變成難聽的崩盤；她不擅長開口求助。雪奈是來聽歌的，這是小夜的場子，不是她的任務；她在乎小夜，也想聽完這一場。回收小隊要東西、要撤得乾淨，雇主不想留下事件紀錄。
- **核心條件**：地下二樓、單一主鐵梯加後巷安全門的老房子，五、六十名一般觀眾，突然停歌或亮燈容易造成推擠；觀眾不知道這兩人的地下身分。小夜決定不停歌——怎麼讓演出與清場同時成立、兩人的節拍怎麼從對不上到咬合，全部交給寫手。
- **自由解題空間**：敵方人數與裝備、戰鬥在哪裡發生、雪奈身上帶了什麼、帳本的真相、觀眾最後看見了什麼、事件如何收尾，皆由寫手自由發揮（嚴禁預排分鏡與解法）。
- **篇幅目標**：約 8,000–10,000 漢字。
- **R 讀者設定**：系列讀者。讀過《雪奈／ZERO NIGHT》多篇近作，認得雪奈、奏、夏音、小夜等主要角色與銀色幽靈的地下名聲；喜歡華麗動作與黑色幽默，對設定說明耐受度低，願意接受留白。
- **閱讀目標（短版，R 冷讀後才看）**：讓人看到兩個平輩同類——一個把戰場混成音樂、一個把音樂當成戰場的節拍——在同一首歌裡從不同拍到彼此聽懂；狂放、華麗、帶黑色幽默，演出本身要好聽，危險要有重量，收尾留在兩人之間不說破的那點餘溫。
