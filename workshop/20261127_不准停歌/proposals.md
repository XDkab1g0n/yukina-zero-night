# 雙寫手 150 字解題與場面提案：〈不准停歌〉

兩位寫手讀同一份 brief、context_brief 與摘錄包，互不知情。

## 寫手 A

**切入**：雪奈的耳朵。窩在吧台邊啃健叔的關東煮聽 set，忽然聽見鐵梯上一雙靴子踩錯拍。她本能地想自己悄悄收掉，結果在人群裡的移動跟小夜的混音撞拍——小夜的反相蓋不住她，就在 drop 裡混進一句只有雪奈聽得懂的損話：「白嫖怪，妳搶拍了。」
**破局**：小夜不關燈清場，而是把清場變成這首歌的編曲：喊全場蹲下合唱、接一段「停電安可」；雪奈改成只在反相吞音的那幾拍動手，用發聲器與彩煙把小隊引進後巷。小隊最後搶走的「帳本」是廢鐵線的歌單；真帳本裡沒有大企業的任何痕跡，只寫著「欠樂手們：一首歌」。
**餘韻**：B.O.S.S. 後小夜進入失聰空白期，雪奈把她的手腕貼在自己腕上打拍給她，讓她知道歌還在。散場照樣算桌子錢，兩人都不說破。

## 寫手 B

**切入**：雪奈視角，吧台邊捧關東煮，懶著但耳朵醒著。她先聽出鐵梯上的腳步不合拍，也聽出小夜的 set 搶了一小節——小夜已經發現了。
**破局**：小夜不停歌，宣布「跟拍上樓的大合唱」，讓觀眾踩著拍子走鐵梯出場。雪奈起初自作主張搶先出手、跟小夜撞拍，被小夜在麥克風上用一句歌詞當眾罵回去；之後她改成只在小軍鼓那一拍出手，把來回收的人一個個拖進錄音室，隔音門一關外面什麼都聽不見。最後的反轉是帳本裡沒有企業的把柄，只有阿柴寫的一頁「全記我帳上」。
**餘韻**：前半互相較勁，後半默契咬合；散場後空場，小夜只為雪奈補完最後三十秒，把壞掉的桌子記到雪奈名下。

## 選定

**主控選定寫手 A**（Charles 授權「照主控推薦」，未逐案拍板）。

- 理由：A 的反相吞音窗口與「停電安可」把清場本身寫成編曲，最貼近閱讀目標的「狂放、華麗」；B.O.S.S. 空白期裡雪奈以腕上打拍「把歌還給她」是全案最強的收尾意象，且直接用到小夜 §7.2 的真實代價。假帳本＝廢鐵線歌單帶黑色幽默。
- B 的錄音室隔音門、讓觀眾跟拍上樓疏散在空間上更穩，但與 A 不拼接；A 的寫手可自行判斷如何處理觀眾安全。
- 給入選寫手的提醒（只傳客觀條件）：B.O.S.S. 是整區效果，滿場觀眾時需有能成立的條件（見 context_brief「本篇客觀現況」）。
- **方法觀察**：兩份提案高度收斂——同樣的開場（吧台、關東煮、聽出鐵梯腳步錯拍）、同樣的「雪奈先自作主張→被小夜在台上損回」、同樣以帳本裡只有阿柴人情話作反轉、同樣以桌子錢收尾。差異主要在清場手法與收尾意象。本次雙提案拉開解法的幅度明顯小於〈靜默月台〉，原因可能是 brief 的開局寫得具體（滿場、雪奈是觀眾、吧台與健叔）；記入 tally。
