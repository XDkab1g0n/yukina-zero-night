# R3 評審意見

### 一、逐篇挑刺（含上面五問的回答）

- **稿件1（粉筆記號／輪椅女孩）**

  **挑刺**
  1. 空間自相矛盾（可小修）：第 3 段從車窗看，步廊「步廊另一頭沒入一座玻璃外牆的物流大樓」；但後文是「步廊的東段貼著那座物流大樓的側面延伸」，終點則是「步廊的盡頭是一棟舊辦公大樓的三樓電梯廳」。步廊盡頭到底接哪棟樓，前後對不上。只要改第 3 段一個動詞就能解決，不構成否決。
  2. 第 3 段開場的城市分層有點報菜名：「大樓再往上有更高的空橋，空橋上方是送貨無人機排成虛線的航道」。疊到第四層時，讀者已經不再看畫面，只是在數層數。同段「橫過大街」與後文「橫跨一段高架快速道路和一條水泥護岸的運河」也有點鬆，不算矛盾，但地形在讀者腦中會晃。
  3. 劇情漏洞：中段那台「7」號電梯「通往下面的運河步道」。女孩既然要「到下面」，又急著趕三點，讀者會問她為什麼不搭這台。文中沒有任何一句交代，讀到她說「繞回去要四十分鐘」時，我倒回去重看了一次。
  4. 視線問題：「她回頭看它，看它下到第二圈那個平台」。這時雪奈已在步廊東段，坡道在西端還繞在樓外牆上，她從哪裡看得到第二圈平台？要嘛給她一個探出欄杆的動作，要嘛承認看不到、改成看輪痕。
  5. 走扶手那段是標準的「強女主炫技」：「走得比在地上還輕鬆」是告知句，換成任何一個身手好的角色都成立。好在下一段「她平常會走的那條路」把這份身手轉成對照組，算是救了回來。
  6. 「今天畫的」這個推論跳太快：前一句只證明「畫上一兩天，粉筆早該被潮氣糊成一片」，推得出「最近」，推不出「今天」。小事，讀時會頓一下。

  **五問**
  1. 沒看過的發展：用一個「不能走樓梯的人」的路線去重讀整座立體城市，而且讓送貨機器人替謎底作證：「和牆上那道波浪線一模一樣的弧。」接著從機器人推出解法：「它也不會走樓梯。」機器人走得到的路，輪椅就走得到。這個邏輯我沒在別處讀過。「7」的解法也漂亮：「像是畫的人已經把手臂伸到最長，卻沒辦法再往前靠近一步。」
  2. 拿掉名字還認得出來。她憑一時興起行動（「可是我等一下就沒興趣了啊」），寧可自己猜也不讓 AI 代勞（「不要講。」「我自己猜。」）。最獨特的一筆是她從別人的憤怒裡認出自己：「這句話她很熟，通常是從她自己嘴裡出來的。」接著她道歉卻不加「可是」。她是一個極強、但很討厭被人當成需要照顧的人，所以懂得怎麼不去照顧別人。這不是隨便一個很強或很可愛的角色。
  3. 想。讀到「7」號電梯時我已經想知道畫記號的是誰；讀到輪椅出現，又想知道她會不會被拒絕；結尾的鐵門、三點，還有那件「什麼東西會結束」，三個鉤子同時掛著。
  4. 要倒回重看的是上面第 1、3 點（步廊終點、7 號電梯為什麼不搭）。想跳過的是第 3 段的城市分層。出戲處很少，導航員兩次被打斷（「不要講。」、敲頸環）都是角色的選擇，不是作者在解說。
  5. 最喜歡的瞬間：「女孩的重心往前送。／粉筆還在半空。」到「那截粉筆落地，啪地斷成兩段」。不寫她怎麼衝過去，只寫一截粉筆還沒落地，速度全藏在空白裡。這是三篇裡最好的一個動作鏡頭。

- **稿件2（跳舞機排行榜／HIBARI）**

  **挑刺**
  1. 邏輯錯誤（可小修）：「右腳則在每一次該落下的瞬間多停一下，停得和影子一樣久」。如果她的判定和影子逐格相同，這一段雙方得分應該一樣，她在一百四十幾步建立的領先不會被「慢慢吃回來」，更不可能最後落後。要輸，就得慢得比影子更多。這個錯是讀過音遊的人一眼就會挑的。
  2. 說明比例偏高。投幣計數器、上鎖小門、旋鈕、影子對戰模式，每一項都要先解釋一次：「上榜的每一筆成績都會被存成一道影子，對戰時……」這不是報菜名，因為每一項都是解謎零件；但讀起來像推理小說的物證清單，溫度被壓低了。
  3. 「補不回來，是因為踩下去的那個人感覺不到」整段是作者替讀者把結論講完。後面「一條還沒習慣的右腿。」已經夠了，前面那段可以砍一半。這段我讀了兩次。
  4. 「被超過一千兩百分就不一樣了。那是一個先把她的分數看清楚，再剛好跳過去的人。」這句立了一個動機（對方衝著她來），後文卻沒有回收。HIBARI 到底是不是衝著 NEMUI 來的，整篇沒再碰。
  5. 「影子也沒有，可是影子跳的時候，頭上根本沒有車。」這是氣氛句，卻放在推理鏈裡，讀者會誤以為它是證據，其實它什麼也證明不了。
  6. 前提略偏：cold_context 說「沒有任何安排」，這篇卻是「為的就是趕在週三以前多跳幾次」。不嚴重，但這是三篇裡唯一有明確目的地的。

  **五問**
  1. 沒看過的發展：透過影子對戰的判定，讀出一個陌生人身體的狀態（「右側平均延遲十四毫秒」），然後故意輸，再把訊息踩進排行榜名稱裡：「み、ぎ、空格、お、そ、い。」用排行榜當信箱，這個設計很新。
  2. 認得出來。她懶（NEMUI、「中段還打了個呵欠」），在意排名卻只在意「剛好」被超過，嘴硬（「腳滑。」），而且用一種對方未必會察覺的方式付出。「用你這個膝蓋。」那種頂嘴也很有個性。不過「手插口袋、上半身不動照樣滿分」是常見的天才姿態，個人辨識度靠的是後半段的讓分，不是跳舞本身。
  3. 想。讀到「沒投錢，可是有人玩了」時懸念最強；影子對戰開始後，我最想知道這個人是誰。
  4. 要倒回重看的是第 3 點那段推理，以及第 1 點的分數計算。想跳過的是計數器與鑰匙那段物證交代的後半。出戲處：導航員那句「主人，人類的腳做不到這麼整齊」太像是為了讓主角接話而設的提詞。
  5. 最喜歡的瞬間：「那孩子出院才一個月。」加上前一句「柘植很久沒說話。電車又從頭上壓過去」。整篇的物證都在這一句裡變成人。

- **稿件3（奏的吃到飽／今川燒攤）**

  **挑刺**
  1. 開場是常見的福爾摩斯式推理秀：「裙子。腰是鬆緊帶的。」從鬆緊帶推到吃到飽，可愛，但這個橋段讀者見過太多次，而且推得太順，等於作者直接把答案遞給她。
  2. 表參道那段可以整段拿掉：「預估等待時間，九十五分鐘。」除了一句「回籠覺比較好吃」，這段沒有推動任何東西。我想跳過。
  3. 象徵太露骨：「最上面那張寫著 reluctant」。作者在對讀者眨眼，提醒你宇佐美很不情願，後文又把她「顯然很不想做的題目」寫了出來，重複了。
  4. 作者代為解釋：「她自己說了出來，大概是不說出來，就沒辦法決定下一步」。這是旁白在替角色找理由。
  5. 秒會技能的套路：「她沒有先挑起來看顏色，每一個都只轉一次手腕」，看十分鐘就比代班的孫女還熟練。接著宇佐美說「……妳到底是什麼人。」這句台詞是動漫式驚嘆，出戲。
  6. 小矛盾：雪奈說「我在旁邊看了十分鐘耶」，但她聽見叩叩聲後立刻叫了「班長？」，之後是點餐、等兩分鐘、吃、拍照、電話。說十分鐘勉強說得過去，但她不是「在旁邊看」，是一直在講話。
  7. 句意不清：「宇佐美來不及說『不是那樣』。」不是哪樣？我倒回去看了一次，還是不確定她要糾正的是什麼。

  **五問**
  1. 沒看過的發展：沒有。雪奈對奏的醋意（「好。」「我生氣了。」）用一隻擠進鏡頭的手觸發，這個觸發點很細；但「幫同學顧攤、讓她去考試」是熟悉的日常系結構。
  2. 半認得。她懶、聰明、用捉弄表達在意（「我說不告訴妳，是因為告訴妳的話，妳吃到第三盤就會想過來看我。」這句很好）。但到了攤位那段，她變成「什麼都一學就會的萬能學姊」，個性被技能蓋過去。
  3. 一半。奏離開後到白鷺橋站前，我不太在意接下來會怎樣；聞到紅豆味之後才重新提起興趣。
  4. 要倒回重看的是第 7 點。想跳過的是第 2 點的表參道。出戲處是第 5 點「妳到底是什麼人」，以及 reluctant 那張單字卡。
  5. 最喜歡的瞬間：「阿綾怎麼換成這麼小的一個了？」接著「卡士達一個，一百二。」把宇佐美交代的「不要跟她算」原樣回收，收得乾淨又有人情味。奏 20 秒替她綁頭髮那一段也很好。

### 二、橫向比較

- **好不好看**：稿件1 > 稿件2 > 稿件3。稿件1 的謎底同時是一個有脾氣的人，稿件2 的謎底大多停在線索上，稿件3 沒有謎、只有暖。
- **人物**：稿件1 > 稿件2 > 稿件3。稿件1 讓雪奈在別人身上認出自己而退讓，稿件2 讓她用讓分表達善意，稿件3 的她到後半被技能取代。
- **自然度**：稿件3 > 稿件1 > 稿件2。稿件3 的家常對白最順，稿件2 的物證交代與導航員提詞最刻意。
- **節奏**：稿件2 > 稿件1 > 稿件3。稿件2 一路收緊沒有贅段，稿件1 開場的城市描寫稍慢，稿件3 有整段可刪的表參道。
- **讀不讀得懂**：稿件3 > 稿件1 > 稿件2。稿件1 卡在步廊空間與 7 號電梯，稿件2 的毫秒推理與分數邏輯要倒回重讀。

### 三、最終投票

最終投票：稿件1

決勝理由：稿件1 和稿件2 都有原創的謎，但稿件1 的謎底是一個會回嘴「誰叫妳碰我的椅子」的人，雪奈因此有一個真正的性格瞬間，而稿件2 的 HIBARI 始終沒有出場。「粉筆還在半空」是三篇裡唯一讓我停下來重讀、只因為寫得好的句子。結尾的鐵門、三點，加上一句「不准推」，讓我最想翻下一頁。

### 四、勝出稿入庫前必改

1. **步廊終點矛盾**
   - 原句：「步廊另一頭沒入一座玻璃外牆的物流大樓」
   - 改法：「步廊另一頭擦過一座玻璃外牆的物流大樓，再往前沒入一片看不清的舊樓群」，或只寫「步廊貼著一座玻璃外牆的物流大樓延伸出去」。要和後文「東段貼著那座物流大樓的側面」「盡頭是一棟舊辦公大樓的三樓電梯廳」一致。

2. **7 號電梯為什麼不搭**
   - 原句：「中段有一座小電梯，通往下面的運河步道」
   - 改法：在這裡或女孩的台詞補一句，交代運河步道到不了她要去的地方。例如女孩說「繞回去要四十分鐘」之前加一句：「中間那台只到河邊，河邊步道過不了橋。」

3. **機器人那段的視線**
   - 原句：「她回頭看它，看它下到第二圈那個平台」
   - 改法：給她一個可行的觀看位置，例如「她走回欄杆邊探出身，看它下到第二圈那個平台」；或乾脆讓她晚一點走回去時看到格柵前的新輪痕。現在的位置看不到那個平台。

4. **城市分層減一層**
   - 原句：「大樓再往上有更高的空橋，空橋上方是送貨無人機排成虛線的航道。」
   - 改法：只留一層，例如「大樓頂上，送貨無人機排成虛線的航道」。後面「一層壓著一層」那句的效果不變，開場少一點清單感。
