# 四點十二分

燕屋那台跳舞機的排行榜上，NEMUI 已經在第一名掛了十一個禮拜。

今天它掉到第二。

雪奈站在機台前，右耳還塞著一邊白色耳機，連硬幣都沒摸出來，就看著待機畫面一頁一頁輪播。她最常跳的那首曲子、最高難度的榜單，第一列寫著 HIBARI，分數比她多一千兩百多分，日期是今天，時間是 04:12。輪播翻到下一首，她伸手按住選曲鍵，把畫面扳回來，又看了一遍。數字沒有變。

她上一次刷新紀錄是三週前，隨便跳的，中段還打了個呵欠。被人超過一萬分，她頂多哼一聲；被超過一千兩百分就不一樣了。那是一個先把她的分數看清楚，再剛好跳過去的人。

頭頂上，電車從高架橋壓過去。整間店跟著低低地震，兩排夾娃娃機的玻璃一起嗡嗡作響，不知道誰忘在退幣口的一枚十圓硬幣在鐵盤裡跳了兩下。燕屋開在舊環狀線的高架底下，鐵捲門內側貼著一張影印的公告：高架補強工程，本店將於本月底結束營業，感謝多年照顧。跳舞機的側板上另外黏了一張便條，是老闆的字：已售出，週三搬走。

雪奈今天睡到十一點，啃了兩片吐司就出門，為的就是趕在週三以前多跳幾次。

「老闆。」

柘植從櫃台後面抬起頭。他六十幾歲，老花眼鏡推在額頭上，手裡捏著一支削得很短的鉛筆，面前攤著一本邊角捲起來的帳簿。

「你幾點開店的？」

「十點，跟平常一樣。」

「那四點十二分，是誰在這裡跳舞？」

眼鏡從他額頭上滑下來一點。他看了她一眼，又越過她看向機台，好像該回答問題的是那台機器。

「機台的時鐘不準。」

「不準多少？」

「快個五、六分鐘吧。」

「所以是四點六分。」雪奈說，「還是四點。」

柘植嘆了口氣，從櫃台後面繞出來。他右手一路扶著櫃台邊緣，繞過轉角那兩步走得特別慢。到了機台前，他把帳簿翻到最後一頁給她看。燕屋每台機器的投幣口下方都有一個機械計數器，他每晚關店前用鉛筆抄一次，抄了二十幾年。昨晚那一格是一串七位數，後面打了個小勾。

他彎下腰，對著投幣口下方那扇小窗瞇起眼睛，把數字一位一位念出來。和帳簿上一模一樣。

「昨晚關店以後，沒有人投過一枚硬幣。」他直起腰，膝蓋喀地響了一聲，「所以沒人來過。是機器自己亂寫的。」

雪奈沒回答。她從帽T口袋裡掏出一枚百圓硬幣，投了進去。

開場音樂響起來，小得幾乎聽不見。

平常她一站上踏板，第一聲鼓點會從腳底和背後的喇叭一起撞上來，連高架上的電車都蓋不過。現在那段前奏細細的，像隔壁房間有人開著收音機。她回頭看柘植。

柘植的臉色變了一點點。

「音量你今天動過嗎？」

「沒有。」

「那它昨天晚上就這麼小聲？」

「……昨晚好好的。」

「旋鈕在哪裡？」

他沒有馬上答。雪奈也不需要他答。她蹲下去，用指節敲了敲投幣口下方那片上了鎖的小鐵門，裡面傳出空空的回音。音量、服務鍵、免費遊玩的開關都在這扇門後面，不投幣也能玩，就只有打開它這個辦法。

「沒投錢，可是有人玩了。」她仰著臉看他，「玩之前還先把聲音轉小，怕吵到樓上。老闆，你住樓上吧？」

「鑰匙只有一把。」柘植把手伸進圍裙口袋，掏出一大串鑰匙，晃得叮噹響，「一直在我身上。」

「那就是你四點起來跳舞。」

「用我這個膝蓋？」

「用你這個膝蓋。」

柘植瞪著她，她也瞪回去。過了兩秒，柘植先把鑰匙收進口袋，又掏出來，挑出其中一支，蹲下去開那扇小門。蹲到一半，他扶著機台側板停了一下，才把整個人放下去。他把旋鈕轉回原位，關門，上鎖，起身時又扶了一次側板。

「玩妳的。」他說，「投了錢就跳。」

前奏已經跑了一半，音量猛地回來，鼓點從踏板底下竄進她的鞋底。雪奈退開一步，按了返回鍵。

「欸，我的一百圓——」

「我又沒說不跳。」

她在選曲畫面往下捲，捲到最底下一個平常沒人碰的選項：與排行榜紀錄對戰。上榜的每一筆成績都會被存成一道影子，對戰時，影子每一步踩得準不準，會和自己的判定並排亮在畫面右側。她選了那首曲子，選了最高難度，選了 HIBARI。

然後她從手腕上拔下兩條黑色髮圈，一條咬在嘴裡，用另一條把披在背後的銀髮在左耳下攏成一束，再換手綁右邊。兩束低馬尾垂到肩胛。她把耳機從右耳摘下來塞進帽T口袋，順手把兩隻手也一起插了進去。

柘植看著她的手。「後面有扶桿。」

「我知道。」

第一個箭頭升上來。

那是這台機器上最快的一首曲子，前三十秒就把四個方向的箭頭撒成一整片。雪奈的上半身幾乎沒動，帽T的寬袖子垂在兩側，口袋裡的手連拳頭都沒握，看起來像一個在月台上等車等得很無聊的人。動的只有膝蓋以下。帆布鞋落在每一格踏板的正中央，踩實的同時已經離開，左、右、左後、右前，鞋底拍出的聲音又乾又密，一聲疊著一聲，中間沒有一點拖泥帶水。兩束低馬尾跟著她換腳時的轉肩，慢半拍地甩，剛甩到右邊，她的重心已經回到左邊了。

畫面右側，HIBARI 的影子和她並排跑。

一開始她只看出它很準。左邊的箭頭，影子每一個都是 PERFECT，連中段那串交叉步也沒掉。右邊的就不一樣，每一個都是 GREAT，底下多標一個小小的 SLOW。

第十個是這樣，第三十個還是這樣。到了副歌，箭頭密得連成一條梯子，正常人在這裡會亂，有幾腳早、有幾腳晚，偶爾整個踩空。影子沒有。它右邊的每一步都剛好慢那麼一點，不多也不少，從頭到尾一模一樣。

副歌第二輪，一班電車從頭上壓過去，整塊踏板跟著發顫，箭頭底下的鐵板像被人從下面敲了一記。雪奈的腳沒有因此早或晚。影子也沒有，可是影子跳的時候，頭上根本沒有車。凌晨四點，末班車早就開走，首班還沒來，整條高架只剩下風。

雪奈的眉毛動了一下。

『右側平均延遲十四毫秒。』導航員的聲音貼著頸側的骨頭傳上來，很輕，『誤差不到一毫秒。主人，人類的腳做不到這麼整齊。』

「機器也不會。」她用只有自己聽得見的氣音說，腳下沒停，「機器發現自己晚了，下一首就補回來了。」

補不回來，是因為踩下去的那個人感覺不到。左腳是自己的，所以左邊一格都沒錯；右腳每一次都在那個人想踩的時候，又多等了一下才落地。那個人跳得夠好，好到每一次都晚得一樣多，卻還不知道該提早。

一條還沒習慣的右腿。

她在一百四十幾步的地方追過了影子。畫面上方的分數條，她那一條往前多探出一小截。

柘植站在她斜後方，一直沒出聲。雪奈聽得見他的呼吸，比剛才蹲下去開門的時候還淺。

最後一段，她把右腳放慢了。

左腳照舊落在每個箭頭的正中央。右腳則在每一次該落下的瞬間多停一下，停得和影子一樣久，然後才踩。畫面右側的兩排判定，忽然變成同一種顏色：她的右邊開始一格一格亮起 GREAT 和 SLOW，和 HIBARI 的並排著，一個接一個，連閃爍的節拍都對得上。分數條探出去的那一小截被慢慢吃回來，最後縮到影子後面一點點。

背後的柘植吸了一口氣，忘了吐出來。

結算畫面跳出來。HIBARI 第一，她第二，差了不到三百分。

輸入名稱的畫面亮起，游標停在第一格，預設帶出上一次的名字，NEMUI 五個字母排在那裡。她用腳把它們一個一個退掉，切到平假名，慢慢踩出六格。

み、ぎ、空格、お、そ、い。

柘植湊過來，念出聲：「……『右邊，慢』？」

「給那個人的。」雪奈這才把手從口袋裡抽出來，把耳後一綹甩亂的頭髮撥回去，「右腳才換沒多久吧。每一腳都晚一樣多，晚得很乖。提早一點點踩就好了，那個人自己不知道。」

柘植很久沒說話。電車又從頭上壓過去，夾娃娃機的玻璃再嗡了一輪。

「那孩子出院才一個月。」

他說完，像是自己也沒料到會說出口，把眼鏡推回額頭上，轉身往櫃台走。走到一半，他背對著她問：「妳的名字呢？十一個禮拜，就這樣不要了？」

「認得出來的。」雪奈說，「第二名原本寫什麼，那孩子比誰都清楚。」

她跳下踏板，跟到櫃台前。櫃台旁的柱子上貼著一張發黃的告示：十八歲未滿及高中生，晚間十點以後謝絕入場。底下蓋著轄區警察署的章。

雪奈盯著那張告示看了一會兒。

「老闆。」

「不行。」

「我還沒說。」

「妳是神山的學生。」柘植頭也沒抬，鉛筆在帳簿上記下她剛才那一百圓，「平日穿制服來過，我看過。十點以後不准進來。」

「上面寫晚間十點以後。凌晨四點已經算早上了吧。」

「凌晨四點我這裡沒營業。」他總算抬頭，從眼鏡上緣看她，「沒營業的時候，誰進來都叫侵入。」

「所以那孩子是侵入。」

柘植的鉛筆停住了。

雪奈把下巴擱在櫃台上，看了他一會兒，然後笑了，露出一點小虎牙。

「放心啦，我不會來。」她直起身，「禮拜三之前我再來一次。」

「白天。」

「白天。」

推開門出去，下午三點多的太陽斜斜地照進高架底下，柱子的影子一根一根橫在人行道上。雪奈把耳機塞回右耳，沒放音樂，從口袋裡摸出一顆檸檬糖，剝開塞進嘴裡。

『要幫您記一筆嗎？』導航員說，『「主人在跳舞機上輸給凌晨四點的人，而且是故意的」。』

「腳滑。」

『兩邊的判定我都存了。您滑了六十三次，每次都滑十四毫秒。』

雪奈含著糖，含糊地哼了一聲。走到路口，紅燈。她站在斑馬線前，回頭看了一眼燕屋的招牌，又看了看高架上那排二樓窗戶，其中一扇的窗簾拉得嚴嚴實實。

『所以，您打算讓到什麼時候？』

「讓到那孩子的右腳跟上。」綠燈亮了，她踏出去，「跟上了，我再認真跳一次。」
