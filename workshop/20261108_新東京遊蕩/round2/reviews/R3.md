# R3 評審意見（第二段候選稿）

行號以各稿件檔案的行號為準。

### 一、逐篇挑刺（含五問）

#### 稿件1

**挑刺**

1. **比分遊戲讀不懂（L55–61、L125）。**「好。三比二。」／「讀卡機那個不算，我自己也會看到。」我得倒回去數到底誰贏了哪幾分：感應窗、輪痕、讀卡機、波浪線、對講機，哪個算誰的，文本沒給夠線索。後面「……四比二。」又加了一分，讀者只能硬猜。這個小遊戲本來是在寫兩人較勁的關係，結果讀者被逼去記帳。
2. **報菜名（L13、L17、L45）。**「離地四十公分左右，門框右側嵌著一片火柴盒大小的黑色感應窗」「大約兩公分高」「四個鑽得很新的螺絲孔，排成一個巴掌大的長方形」。只看單句都有用處，可是門前那一段連續堆了五、六個尺寸，讀起來像勘驗報告。L15 的結論「會開門的東西全部在膝蓋以下」是好句，前面那些鋪陳應該砍掉一半。
3. **台詞太刻意（L150）。**「然後他們就可以說，有替代路線。」角色直接把作者的諷刺講了出來。前面那張 A4 加上還沒裝的對講機，讀者自己就看得懂，這句是把話講白了。
4. **結尾的數數讀不懂（L172–182）。**「一邊推，一邊用很低的聲音數：『一、二——』」，她到底在數什麼？貨梯門早在機器人進去時就開著了，這時候開始數，跟門開多久沒有關係。雪奈喊「六」、女孩說「這個算妳的」，收尾的動作得靠讀者自己補上邏輯，力道因此打了折扣。
5. **和第一段有小摩擦（L9、L15）。**第一段女孩說：「那是東雲的貨運通道。要刷卡。我試過了。」講的是這扇灰門。本稿卻讓雪奈說「這扇沒有讀卡機」，再把她刷過的卡改成玻璃閘門那邊的讀卡機。勉強說得通，但讀者會頓一下。小修就能解決，不構成否決。
6. **一句沒有落點的觀察（L152）。**「想起電梯廳那張公告最後只署了一個名字。這一張多了一個。」我看得出作者想暗示些什麼，讀了兩遍還是不知道它要我得出什麼結論。

**五問**

1. **沒看過的發展：**有。L135–137 的「行動不便者替代通行作業」，要先按一個還沒裝的對講機，再等一個不在椅子上的值班人員。用一份官樣文件寫出無障礙設施怎麼淪為紙上作業，我在類似小說裡沒看過這種冷面寫法。L162 雪奈套上那件反光背心，說「值班人員。」，用一個惡作劇把文件的漏洞補上，也新鮮。
2. **認不認得出主角：**認得。爬上欄杆坐著、雙腿懸在三層樓高的空中（L63），被鏡頭拍到就把帽子拉起來（L101–107）。新面向是她會輸、也會嘴硬，例如「我也猜到了。」（L55）。女孩比第一段更鋒利：她早就跟著機器人畫記號，「比導航準」（L27）。她不再只是被救的人，而是比主角更懂這座城市的人。
3. **讀到一半還想不想往下讀：**想，但動力來自「門到底怎麼過」這個技術題，不是人物。
4. **讀不懂、想跳過、出戲：**比分和結尾的數數要倒回去重看；門前勘驗那段想跳過；L150 那句出戲。和第一段接得很順，第一句「女孩推得不快」直接接上她已經推動輪子。
5. **最喜歡的瞬間：**L123–125，「我是物件。」女孩說，「三秒。」接「我連物件都不算。」兩人用同一個笑話，各自咬了制度一口。

#### 稿件2

**挑刺**

1. **熟悉的套路（L13–25）。**「她是對著雪奈說的。」接「我在這裡。」「我腳不能走。耳朵可以。」旁人不跟輪椅使用者說話、只跟同行者說話，是寫身障角色時最常見的一場戲。回擊那句寫得漂亮，戲本身並不新。
2. **解說型台詞（L51）。**「上禮拜有兩個國中生跟在機器人屁股後面鑽進去，在裡面玩貨梯玩了一個下午，總公司就裝了那個。」這是在幫讀者補背景，交代閘門的由來，可是第一段已經用一塊「四角的螺絲還亮著」的新壓克力板交代過了。這句可以刪掉一半。
3. **主角戲份被第三人拿走。**整段的關鍵進展是宮地刷卡放行，雪奈第一段想出的「它也不會走樓梯」只剩下沿路的路線功能。雪奈在這段主要是旁觀加吐槽，「麵要爛了喔。」（L63）很好笑，但她沒有推動任何事。
4. **巧合偏方便（L121）。**「鶴田的喔。」「他們今天最後一天吧？」一個路人剛好知道答案，替讀者揭開了第一段刻意留白的「結束」。處理得很節制，女孩用「麵要爛了。」一句擋回去，揭曉本身還是靠運氣。
5. **自相矛盾：**未發現。我檢查了時間（2:21→2:31，接得上）、兩截斷粉筆的位置（L1 女孩繞過它們，和第一段「斷成兩段」對上）、蕎麥麵店的位置（宮地從西邊來，對）、灰門要刷卡（對上第一段「要刷卡」）、露指手套的穿脫（L169「脫下右手的手套」，沒問題）。

**五問**

1. **沒看過的發展：**部分有。L43–47 女孩拿自己跟機器人比體重，「我加椅子四十九。」用貨物的邏輯爭取通行權，有新意。L155–167 雪奈把「下一個記號」畫成一碗蕎麥麵，「看不懂的人就會去問啊」，把記號從標路線改成指向某個人，這個轉向我沒看過。
2. **認不認得出主角：**認得。她坐上比手掌還窄的防撞扶手，「整個人摺成小小一團貼著牆」（L107）。新面向是克制：「雪奈的右手已經伸出去一半，又收了回來」（L83），還有 L17 她不替女孩回答，「她轉過頭，看著女孩。」，把第一段那句「這句話她很熟」真正做成了行動。女孩的新面向是她會道謝，「謝謝。」聲音小得有一半被門縫吃掉（L81）；她也會守住自己的事，用一句話擋掉追問。
3. **讀到一半還想不想往下讀：**想。宮地亮出識別證之後，我想知道她會不會放行；文具店的事出現後，我想知道她趕不趕得上。
4. **讀不懂、想跳過、出戲：**沒有讀不懂的地方。L51 那段解說想跳過。L45「女人愣了愣，竟然真的想了一下」很好笑，不出戲。和第一段接得最順：開頭就處理掉那兩截粉筆，結尾把「下一個記號給妳畫」和「走在旁邊」都收了回來。
5. **最喜歡的瞬間：**L169，「圈還是畫得不太圓，起筆在下緣，這次沒有抖。」直接回應第一段那個「抖了一下」的圓，一個字都沒解釋。

#### 稿件3

**挑刺**

1. **和第一段矛盾，可小修（L133）。**「她咬住一隻手套的指尖扯下來」。第一段寫的是「雙手戴著露指手套」，露指手套沒有指尖可以咬。只要改一個動作就好，不構成否決。
2. **輪椅的物理寫反了（L63）。**「她雙手往後一撥，輪椅猛地往前竄出去。」手往後撥輪框是倒退或煞車，往前推才會往前衝。讀到這裡我腦中的畫面卡了一下。
3. **平面圖那段要倒回去重看（L35）。**「黑線的起點旁邊，同樣的字跡又補了一行小字：照粉筆修正。」我第一次讀以為黑線，也就是內部坡道那條路，是照著粉筆修出來的，可是女孩的粉筆從來沒進過這棟樓。重讀才弄懂：配送路線在週末改走內部坡道，而外面那三個藍色記號是照她的粉筆修正的。這是全稿最好的點子，卻擺在最容易讀錯的位置。
4. **開頭的戰術說明偏長（L5）。**「它出來以前，會先停在門檻上看外面有沒有東西。看完才出來。後輪一離開那條黃的，門就開始關。」女孩替讀者做了一次簡報，好在後面接了一句「我只是好奇」，把它救成角色特質。
5. **位置交代含糊（L25）。**「雪奈等她兩個大輪子都過了門檻，才從門軌上退開。門在她背後滑上」，雪奈退到門內還是門外？下一段兩人已經在門裡，只能用推斷補上。
6. **主角能力的尺度（L83）。**一腳把一台四十幾公斤的機器人踢轉半圈，比第一段走扶手的身手高了一級。第一段已經鋪過她的身體能力，我接受，但這已經是上限，再高就變成超人戲了。

**五問**

1. **沒看過的發展：**有，而且有兩處。第一處是 L31–41：物流公司的平面圖抄了女孩的粉筆，第一段「波浪線學機器人」的因果在這裡倒了過來，「原來是它學妳。」／「誰教它的？」。第二處是 L109–117：簾縫裡只看得見「全是腰以下的東西」，女孩把自己折到胸口貼膝蓋去試那個洞，背還是高出一截。這一幕用身體量出這座城市為誰而建，我在類似小說裡沒看過。
2. **認不認得出主角：**認得。第一段那句「這條很笨的坡道」在 L51 變成「這棟樓裡面也藏了一條笨坡道。」，笑出聲的方式一模一樣。新面向是她會用身體擋門，卻守著「不准推」的字面規則，L105「它又沒說不准推。」；她陪跑時「不前，也不後」，L69 一句「是妳說要走在旁邊的。」把女孩的命令變成遊戲。女孩的新面向是速度與快樂：放手讓椅子滑下坡，「這一次，她的嘴角是往上的。」（L71）。她也變得叛逆，願意去按會響警報的門，「這次妳不准擋。」（L147）。
3. **讀到一半還想不想往下讀：**非常想。平面圖丟出「誰在看她的粉筆」，坡道丟出速度，簾子丟出死路，最後那個男聲把問題全部收進一個人身上。三篇裡只有這篇讓我翻到最後時想立刻看下一段。
4. **讀不懂、想跳過、出戲：**平面圖那段要重看，L63 物理寫反的地方會卡一下。沒有想跳過的段落：坡道追逐那場在三篇裡節奏最好。台詞沒有出戲。和第一段接得順，開頭直接在門前，也延續了「三點」的壓力（L133 看手機、L135 默算回頭的路）。
5. **最喜歡的瞬間：**L103–105，「……妳推它。」／「它又沒說不准推。」把第一段的最後一句變成笑點，同時也是一種溫柔。

### 二、橫向比較

- **好不好看：**稿件3 > 稿件2 > 稿件1。3 有動作、有意象、有懸念；2 動人但收得太滿；1 聰明但讀起來在解題。
- **人物：**稿件2 > 稿件3 > 稿件1。2 讓雪奈的克制和女孩的自尊都落在具體動作上；3 給了女孩快樂和叛逆；1 的雪奈被寫成嘴硬的輸家，女孩則多半在解說。
- **自然度：**稿件2 > 稿件3 > 稿件1。2 的對話最像真人在講話；3 開頭有一段簡報味；1 有一句作者代言的台詞，還有一整段勘驗報告。
- **節奏：**稿件3 > 稿件2 > 稿件1。3 從靜止、發現、加速、險情到死路，一路有起伏；2 前半段被宮地的解說拖慢；1 卡在門前蹲查太久。
- **讀不讀得懂：**稿件2 > 稿件3 > 稿件1。2 沒有要重讀的地方；3 只有平面圖一處；1 的比分和結尾的數數都要倒回去看。

**每篇在做什麼：**

- 稿件1：兩人一起拆解一扇為機器設計的門，發現官方給輪椅的替代方案只存在於紙上，最後用一場變裝把那張紙兌現。
- 稿件2：一個陌生人的偏見和一條規則，被一次很小的人情鬆動；女孩靠談判過關，主角守住「不代她說話、不碰她」，兩人兌現了記號的約定。
- 稿件3：兩人鑽進機器的隱藏路線，發現系統一直在偷學女孩，卻只為腰以下的東西開門；最後被那個一直在看的人逮住。

**是不是在講同一件事：**三篇的底都是「城市為機器開路，不為她開路」。1 和 3 幾乎是同一個命題，1 拿文件來諷刺制度，3 用身體和空間把它演出來。2 換了一條路：它把答案交給一個人的選擇，而不是去控訴系統。所以 1 和 3 講的是同一件事，2 是另一件。

### 三、最終投票

最終投票：稿件3

決勝理由：只有稿件3把第一段的發現往前推了一大步，讓「波浪線學機器人」反轉成「機器人學她」，並用簾縫「全是腰以下的東西」與女孩折身試洞的畫面，把主題變成讀者忘不掉的身體經驗。坡道追逐和「它又沒說不准推。」寫活了兩人的關係，那份快樂是另外兩篇都沒有的。稿件2 人物最好，但它把戲份交給第三人、把懸念收乾淨了；稿件3 的錯都是一句就能改的小錯，好看的程度卻高出一截。

### 四、勝出稿入庫前必改

1. **露指手套矛盾（L133）**
   - 原句：「她咬住一隻手套的指尖扯下來，看手機。」
   - 改法：「她撕開魔鬼氈，把一隻手套扯下來，看手機。」
2. **輪椅推進方向（L63）**
   - 原句：「下一段直線，她雙手往後一撥，輪椅猛地往前竄出去。」
   - 改法：「下一段直線，她雙手往前一送，輪椅猛地竄了出去。」
3. **平面圖的因果容易讀反（L35）**
   - 原句：「旁邊是另一種字跡：『週末停駛，改走內部坡道』……黑線的起點旁邊，同樣的字跡又補了一行小字：照粉筆修正。」
   - 改法：把電梯廳那行改成「週末停駛，配送改走內部坡道」，再把「照粉筆修正」移到外面那三個藍色記號旁邊，例如：「坡道、平台、中段電梯那三個藍色記號旁邊，同樣的黑色字跡補了一行小字：照粉筆修正。」
4. **雪奈進門的位置（L25）**
   - 原句：「雪奈等她兩個大輪子都過了門檻，才從門軌上退開。門在她背後滑上，喀地扣住。」
   - 改法：「雪奈等她兩個大輪子都過了門檻，才從門軌上退進門裡。門在她背後滑上，喀地扣住。」
