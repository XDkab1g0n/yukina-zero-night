# 構想 C（第二版）｜清除之後

## 各方欲望
- 琉璃：想要四天沒有用途的時間，而且只屬於她自己。目的地是新創的阿爾卑斯山谷信託市「格倫茨塔爾」，當地把人工生命的記憶算成「境內產生的機械記錄」，出境時要交副本給資料信託，或是自行清除。多數機器都選清除。琉璃出發前就決定好要清除，但沒有告訴任何人。武裝留在身上，入境時由當地海關用鉛封把武器埠封起來。
- 雪奈：知道防衛省輸出管理課把「回收受管制模組的境外使用紀錄」寫進出口條件，已經向信託預約調閱那份副本。交出副本，等於把琉璃的心送進省裡；清除，則等於琉璃白去一趟。所以她謊稱發燒，提前進城，透過地下管道打通出境查驗的第四號窗口，準備用一份偽造的紀錄過關。
- 潔西卡：班代，處理全班的雜事。她察覺琉璃在「告別」每樣東西，於是正面質問。

## 骨架
一個記憶會被沒收的人出國旅行，打算回程時把整趟忘掉，才不會讓任何人拿到副本。最愛她的人瞞著她鋪好一條讓她兩樣都保住的違法捷徑。她在半路撞見對方，決定不走那條捷徑，要對方停手、回到隊伍裡，親眼看完她會忘記的那幾天。出境前，她走向正規窗口，親手清除。

## 開場／結尾
- 開場：邊境車站，當地技師用壓接鉗把鉛封夾上琉璃前臂的武器埠。同一時間，班級群組跳出雪奈的發燒貼圖。
- 結尾：離境列車上，琉璃的紀錄有一段四天的空白。口袋裡有一枚她不記得組裝過的黃銅擒縱輪。雪奈醒來開始講那趟旅行，把數字講錯，琉璃沒辦法糾正，請她繼續講。

## 五個關鍵細節
1. 前臂武器埠上的鉛封，壓上的是當地海關的印紋。
2. 登山齒軌列車在中途會車點交錯，琉璃從車窗看見對向車廂裡的雪奈；雪奈豎起食指抵著嘴唇。
3. 鐘錶工坊的課程裡，琉璃親手組裝一枚擒縱輪。
4. 舊市政廳「三百一十二座鐘」的正午報時，彼此總是差幾秒。
5. 出境查驗廳的第四號窗口與第二號窗口。

## 第一直覺清單（正文一律不用）
- 第一版用過：琉璃自己卸下觸手留在國內；雪奈瞞著她在當地登記成持有人；無主空窗被救助業者申報占有；算錯時間差；橘色腕帶；乘客簿同行人欄簽名；島嶼自由港與渡輪；燈塔霧笛；飯店老電梯超重；潔西卡因十七歲當不了保證人；發燒溫度計照片的反光。
- 新題第一直覺：瑞士風巧克力與起司鍋；咕咕鐘當紀念品；雪奈潛入山體資料金庫上演駭客劫案；琉璃把記憶加密藏進雪奈的樞紐裡偷渡出境；同學送紙本相簿替她保存回憶；結尾琉璃發現自己偷偷留了一份備份；雪地裡打雪仗；關鍵台詞「就算忘了，我也會再喜歡上」。
