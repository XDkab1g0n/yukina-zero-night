# 讀者 C 審稿

### 一、逐篇挑刺

#### 稿件1〈第二號窗口〉

**問題**

1. **時刻算不攏（自洽）**：第七章「三天又十二小時，每一條都完整」、第八章「然後是一段乾淨的斷層，三天又十二小時」。入境戳記是第一天 18:11，清除在第四天約 07:00，中間只有約六十一小時，也就是兩天半。全篇其他時刻（61h41m 鎖到第四天 07:52、鐘廳快 11 秒慢 29 秒、響 40 秒）都算得準，只有這裡錯，反而更刺眼。修：兩處都改成「兩天又十三小時」。
2. **已發生的事對不上（自洽）**：第八章「琉璃最後一次看見那張貼圖，是在邊境站的大廳，在試射之前」。第一章明寫她是「出了試射間」以後，在大廳滑手機才看到鯊魚貼圖。那時已經過了 18:11，這段記憶應該被清掉，順序也跟原文相反。修：改成她記得的最後一次是「那天早上，在東京」。
3. **規則留了漏洞，困境會漏氣（設定破口）**：第一章入境須知「個人隨身裝置不在此限」。讀者馬上會問：那她用手機錄影不就好了？她手機裡跟雪奈的對話（「今晚八點半，鐘錶街十四號」）也會留著，結尾一看就知道。第六章雖然補了「長谷川的相機是自然人的個人裝置」，但第一章的措辭沒有排除她自己的手機。修：第一章改寫成只有自然人的裝置不受限，機械個體攜帶的裝置視同本體。
4. **偏離題目（題旨）**：情境是「目的地的法律把人工生命當成資產」，本篇的法律只處理記錄要交付還是清除，「資產」只在暗處。修：入境須知加一句，明說機械個體算攜入資產，記錄算它的孳息。
5. **主角錯位（視角配置）**：情境說主角是高三女生，可是全篇都是琉璃的視角，雪奈前三分之一只以一張貼圖存在。雪奈仍是推動劇情的人（偽造窗口、拒絕拆掉、最後負責記得），所以不否決；但這是結構選擇，沒辦法小修，入庫時要知道這篇是「從同桌眼中看她」。
6. **推理稍快（角色變聰明）**：第三章「在這座山的某一層裡，做著某件和琉璃的那份副本有關的事」。只看一眼工作服，就推到「和副本有關」。前面埋過「那張條件書，她放在雪奈家客廳的桌上兩天」，勉強撐得住，不必改。
7. **高潮台詞偏成論證稿（台詞刻意）**：第五章琉璃連續三段，「那份假的副本，會在山裡放三十年」→「第四號窗口那位先生」→「然後，是妳」，論點排得太整齊。好在每段之間都有雪奈的反應打斷，情緒撐得住，可以接受。
8. **數字密度**：我檢查過「每六十二公分重複一次」「每秒十一下」「〇點〇二毫米」。這些是琉璃的感知方式，而且結尾刻意翻轉成「一千座」，屬於有功能的數字，不扣分。

**五問**

1. **沒看過的發展**：會車時雪奈「對著玻璃哈了一口氣……字是反著寫的。從琉璃這一側看過去，剛好是正的。38.6」。結尾琉璃「甚至已經把查詢打好了……她把查詢刪掉。『一千座。』」。還有雪奈「我要是拆了，就變成我替妳選了清除……那也是替妳選」：保護者刻意不替對方關掉退路，我沒在同類故事裡見過。
2. **認不認得出她們**：認得。雪奈是懶散、嘴硬、什麼都看在眼裡的人，因為太了解對方反而不敢問：「然後妳就真的刪了……所以我沒問」。她怕遺忘，是因為自己忘過：「像別人家的照片」。去掉名字仍然獨一無二。琉璃是習慣把一切拆成條目的人，這趟旅行學會不拆：「她沒有把它們分開」。她的倫理很具體，連第四號窗口那個欠債大叔「每一次稽核，他都要怕一次」都算進去。
3. **讀到一半還想知道後續嗎**：很想。第二章「出境的時候，我會清除」就勾住了，第三章會車之後是全篇最強的拉力。
4. **讀不懂／想跳過／出戲**：要倒回去重看的是貼圖時間和「三天又十二小時」。出戲的是第一章那條「個人隨身裝置」，它讓整個困境有個破口。沒有想跳過的段落，觀測站驅動鐘那段很短，也替後面的擒縱鋪了路。
5. **最喜歡的瞬間**：列車上雪奈說「一千座」，琉璃刪掉查詢，跟著說「一千座」。整篇最精確的人，把自己交給最不精確的記憶。

**亮點**：擒縱「一次只放一齒」，跟逐幀記錄和人的記憶形成呼應，而且一句都沒點破。結尾的黃銅底板上，「五下，也可能是六下」，是三篇裡最好的一句。

#### 稿件2〈鏡田〉

**問題**

1. **自相矛盾（人物內心前後對不上）**：第六章雪奈的內心先寫「這是琉璃的方案。從一開始就是」，下一句又寫「琉璃算錯了時間，然後在三十秒裡找到第二條路」。到底是預謀，還是臨場？修：擇一。我建議留「從一開始就是」，刪掉「三十秒」那句，讓第二十二條成為她本來就打算當著雪奈的面用的牌。
2. **聰明人被安排算錯，再被安排背出條文（角色忽笨忽聰明＋法條解圍）**：第五章「拾得商……中位數是九十六分鐘」，最謹慎的琉璃拿自己的歸屬去賭中位數；第六章再一字不差背出「第二十二條，第一項」救場。兩步都看得到作者的手。修：配合第 1 點，讓她承認自己是在賭（「我知道會有少數」），把第二十二條寫成備案，而不是急救。
3. **底牌揭曉變成偵探獨白（解說）**：第六章「涼泉冷氣在特許市的商業登記，負責人叫法麗達・哈桑……油錢，比冷氣行一個禮拜的營業額還多」。琉璃一口氣交代自己全部的算計，從人物變成了解說員。修：留「四點十分我打過去」和法麗達那句「客人付錢」，其餘壓成一句。
4. **伏筆掛得太明（巧合）**：第三章「小野寺從今天開始滿十八歲」，第四章潔西卡又說「我十七歲。我還沒滿十八」。讀者在第三章就知道誰會來當保管人，結局的驚喜被提前兌現。修：把年齡資訊藏進第一章的通關（護照、海關問一句），不要放在生日派對上點亮。
5. **秀設定（報菜名）**：第二章「回聲計畫、防衛省和教授的遺產這幾年來一直圍著她打轉」，三個專有名詞一口氣丟出來，對本篇沒有功能。第一章「腕部、掌部、腿部推進、背部六軸」是裝備清單。第四章潔西卡「指尖的地方有一點細細的藍白色火花跳了一下」，突然冒出能力又沒有後續，讀者會停下來問她是什麼。修：前兩處刪名詞、只留「那是我的手」；火花換成普通動作。
6. **繞口令（台詞刻意）**：「她知道。」……「而且妳也知道她知道。」，以及「妳什麼時候知道我知道妳知道？」。作者自己也讓雪奈吐槽「妳在玩繞口令」，等於承認它刻意，可以刪掉一次。
7. **風險實際上偏空（張力）**：蕾娜說「十一點五十二分以後，妳就是他們的了」，「他們」就是雪奈。所以東稜那場賭局的最壞結果，是琉璃歸雪奈，這她早就知道。真正的危險（市警、九十天）只有雪奈動手才會觸發。張力靠雪奈的克制撐著，不是靠處境。
8. **過度修辭**：「那是雪奈這輩子被看過最平靜的一眼。」誇大，刪掉「這輩子」就好。

時刻我逐一核過：16:05 加 47 分是 16:52；23:52 中斷，到 05:05 剩 6h47m；05:18 出門到 06:03 再加 3 分 40 秒，約 49 分；05:52 到 06:30 是 38 分；看到 11 分鐘。全部對得上，是三篇最工整的。

**五問**

1. **沒看過的發展**：雪奈隔著磨砂玻璃數壓接鉗的聲音，導航員跟她爭「剛剛那聲不算，那是她在調鉗子」，出境時再反過來爭一次。空殼公司以抱枕「鯖鯊」命名，好讓對方查到時認得出是誰。琉璃利用法律上「不屬於任何人」的十二小時，只為了「用其中三十八分鐘，看這個」。這三個我都沒看過。
2. **認不認得出她們**：認得。雪奈什麼都先排好，連「被邀請之前，就把邀請的行程排好了」；她要兩件互相矛盾的事：「我兩件都要」。琉璃拒絕「把手留在家裡」，想要一段沒有歸屬的時間，被冒犯和被珍惜同時發生時分不清是哪一個：「被這樣要走，好像也不是只有可怕」。配角群三篇最強：蕾娜、杉浦、安達、小野寺。
3. **讀到一半還想知道後續嗎**：想。冷氣車和中斷倒數是三篇裡最強的懸疑引擎。
4. **讀不懂／想跳過／出戲**：要倒回去重看的是第六章「從一開始就是／三十秒」這組矛盾。出戲的是潔西卡的火花、小野寺的生日，還有法麗達登記資料的揭底。想跳過的是第七章小野寺「這兩天過得很辛苦」那段摘要。
5. **最喜歡的瞬間**：「妳是風鈴。」「我是有編號的風鈴。」

**亮點**：泌尿科那場的醫學判斷又準又有戲，「這種痛到坐立難安、滿地找姿勢的，多半是管子塞住了」，接著安達為了保管問「明天早上再做可以嗎？」，人物在危機裡露出底色。鏡子各自延遲、「比同步好看」的母題，收得很漂亮。

#### 稿件3〈一塊錢水手〉

**問題**

1. **時間表述互相打架（自洽）**：第四章琉璃問「我可以十二點再來嗎？」，特維塔答「到十二點之前，都是妳的時間」。那是上午十點多，讀者自然讀成中午。第五章又寫「那裡今天中午之後就什麼都沒有了」，第六章「下午就沒有了」，但銅牌其實上午十點就被巡查員和特維塔收走了。三處互相矛盾。修：改成「今晚十二點」「午夜」，銅牌改成「今天上午之後」。
2. **解說式身世獨白（巧合＋主題直說）**：第五章特維塔「我父親是水手……船上十四個人，在那艘船上住了十四個月……一人一塊錢，載他們回來」。配角對主角講一段剛好完美對應主題的身世，這是最常見的解題拐杖，而且跟「論斤賣」那段的功能重疊。修：砍到三句以內，或讓雪奈在書架上那本藍色帳冊裡自己看到一行舊紀錄。
3. **條文唸兩次（解說、重複）**：第五章琉璃對潔西卡唸「第八十一條……」「第八十八條……」，第六章特維塔又唸了一次「第八十八條：無海員手冊之外國人……」。修：第五章只講結論（「簽上名冊，我就是船員，不是貨」），條文留給櫃台唸一次就好。
4. **名詞丟擲（報菜名，輕微）**：第一章「六臂單元在鴉巢四號櫃……弁慶，他幫我扶著背板」，一句塞了三個專名。只出現一次，後面立刻轉回情緒，輕微。另外「左紅右藍的眼睛」和後面「一紅一藍」寫了兩次外貌，可以拿掉一次。
5. **風情填充（節奏）**：第五章「村子裡的孩子穿著草裙在前面跳舞……潔西卡……跳得比誰都起勁」，加上地窖烤爐的整段料理描寫，都不推動劇情。第三章導遊解說拆船灘也偏長。修：各砍一半。
6. **擺拍感（輕微）**：琉璃已經對瑪塔說「十二點前我會帶去」，卻從雪奈身邊走過，讓特維塔先拿出收容單，就為了等雪奈自己開口問。這跟前文雪奈「沒問就做」形成對稱，邏輯成立，但看得出是在搭舞台。

**五問**

1. **沒看過的發展**：開場「今天木條彎下去的幅度，跟那個大叔差不多」，雪奈靠一條長椅的下彎幅度，發現琉璃拆了武裝。型號欄填「月見里琉璃」，登記官在後面加「（本人申報）」。最後琉璃把雪奈盤壞的那一圈留著：「那一圈，請留著。」「讓他罵。」這幾處都新。
2. **認不認得出她們**：認得。雪奈習慣先動手替人收拾，邊研修邊勘查保稅倉；這篇讓她學會「等」（「『這是我記錄裡的第一次。』」），而且簽名變慢了，「不是我一個人負責的那種」。她是三篇裡唯一真正有成長弧的主角。琉璃喜歡規矩，也用規矩找自由：「十九年可以嗎？」「我會沉。」
3. **讀到一半還想知道後續嗎**：想。從巡查員對出「這個今天早上七點十二分變更了」那一刻起，張力最高。第三章中段會稍微鬆掉。
4. **讀不懂／想跳過／出戲**：要倒回去重看的是「十二點」到底指哪個十二點。想跳過的是歡送會跳舞和拆船灘導遊。出戲的是特維塔父親的故事，來得太剛好。
5. **最喜歡的瞬間**：「妳的線，從八點十分到現在，一直是鬆的。」一句話揭穿雪奈整個上午的心不在焉，不用任何解說。

**亮點**：所有人和擔保同行人（同約、同船、同值、互相連坐），是三篇裡對題目最精準的回答。盤繩母題從「二十年才盤得這麼平」到「那一圈，請留著」，首尾閉合。

### 二、橫向比較

- **好不好看**：稿件1 > 稿件3 > 稿件2。稿件1 的高點（反寫的 38.6、一千座）最高；稿件3 溫度最穩；稿件2 懸疑最強，但後半靠揭底和解說兌現，用說的多過讓人感受到的。
- **人物**：稿件1 > 稿件3 > 稿件2。稿件1 的雙主角都有一個只屬於自己的傷口和選擇；稿件3 的雪奈弧線最清楚，琉璃稍微平面；稿件2 配角最好，但主角被情節機關推著走。
- **自然度（少堆砌）**：稿件3 > 稿件1 > 稿件2。稿件1 的數字有功能，稿件2 的專名、裝備和能力最常跑出來秀。
- **節奏**：稿件2 > 稿件1 > 稿件3。稿件2 倒數驅動最緊；稿件1 前慢後緊但每段都有用；稿件3 第三章和歡送會會拖。
- **自洽**：稿件2 > 稿件3 > 稿件1。稿件2 時刻全對、只有一處內心矛盾；稿件3 是「十二點」的歧義；稿件1 有兩處硬傷（三天又十二小時、貼圖時序）。

**骨架**（刪掉地點與人名後）：
- 稿件1：保護者瞞著對方替她準備了一條退路；對方發現後拒絕被代為選擇，保護者也拒絕替她關掉退路；她自己選了代價最高的那條，把「記得」託付給保護者不可靠的記憶。
- 稿件2：雙方各自知道對方藏著一份「替你做主」的保險，都不說；危機逼近時，被保護者用自己的冒險逼保護者當眾承認，然後要對方撤銷，改請第三人擔保，只留下「自願並肩」。
- 稿件3：保護者未經同意替對方扛下歸屬；被保護者要求撤回並承受後果，再找到一種共同承擔、互相連坐的形式，邀請對方以平等的身分簽名。

三篇的骨架其實相同，都是「擅自保護 → 拒絕被代為決定 → 重新定義兩人關係」。差別在解法：稿件2、稿件3 都靠一條法條加上一個制度上的出口（第三人保管、擔保同行人）脫身；只有稿件1 沒有解圍，讓主角真的付出全部代價。

### 三、最終投票

`最終投票：稿件1`

三篇骨架相同，只有稿件1 不靠法條或第三人解圍：它讓琉璃真的失去那幾天，再用「一千座」把整篇最精確的人交給最不精確的記憶，這是三篇裡唯一讀完還會留在心裡的結局。反寫在車窗白霧上的 38.6，和「那也是替妳選」，是我在同類小說裡沒看過的發展。它的錯誤是兩處算術和一條規則措辭，小修就能補好。

### 四、勝出稿入庫前必改

1. **第七章**「三天又十二小時，每一條都完整」，以及**第八章**「然後是一段乾淨的斷層，三天又十二小時」：兩處都改成「兩天又十三小時」（第一天 18:11 到第四天約 07:00）。
2. **第八章**「琉璃最後一次看見那張貼圖，是在邊境站的大廳，在試射之前。」改成「琉璃記得的最後一次看見那張貼圖，是那天早上，在東京。」第一章原文寫的就是「雪奈今天早上傳的」，不必再動。
3. **第一章**入境須知「個人隨身裝置不在此限。」改成「自然人隨身的個人裝置不在此限；機械個體所攜裝置內的記錄，視同本體記錄。」這樣能堵住「用手機錄下來就好」的漏洞，也讓結尾琉璃手機裡沒有那段對話，空白更徹底。
4. **第一章**同一段開頭「依本市資料信託法，您在境內產生的所有記錄」改成「依本市資料信託法，機械個體入境即列為攜入資產；您在境內產生的所有記錄，屬該資產之孳息」。只加一句，把題目要求的「人工生命是資產」落到條文上。
