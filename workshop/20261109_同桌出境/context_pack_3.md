# 10. 戰鬥狀態與限制

## 10.1 狀態矩陣

| 狀態 | 主要表現 | 限制 |
|---|---|---|
| 校園低功耗 | 多數武器鎖定，感測器低調運作 | 不主動暴露非人體能 |
| 標準任務 | 兩至三根觸手主動、多光譜分析 | 控制能源與熱 |
| 城市救援 | 觸手、鉗爪、防護與感測優先 | 火力受平民與結構限制 |
| 高烈度戰鬥 | 多武器協同、推進與電子戰 | 並行與散熱快速上升 |
| 重甲拆解 | 腕炮、高頻刃、結構分析 | 能耗高、需要支點 |
| 感測受騙 | 降低自動信任，依靠物理交叉驗證 | 反應速度下降 |
| 過熱 | 武器降級、光效增亮、語速更短 | 可能永久損傷 |
| 核心受損 | 分區關閉、觸手減少、保存人格與移動 | 不可無限硬撐 |
| 情感高壓 | 計算仍在，但價值權重快速變化 | 可能過度保護或拒絕撤退 |

## 10.2 明確弱點

* 高功率並行造成過熱；電磁干擾與感測欺騙；能源與彈藥有限。
* 關節、冷卻管路與主核心是關鍵弱點。
* 體重與骨架強度高，但地面、建築和支點不一定能承受她的輸出。
* 水、粉塵、腐蝕與極端環境會影響模組；維修需要時間、零件與可信任技師。
* 她可以繼續戰鬥至高度受損，但身體損壞、感測缺失、計算錯誤與人格連續性風險必須實際存在。

# 4. 人格、欲望與價值

## 4.1 表層人格

* 大聲、直率、競爭心強，喜歡正面回答，不擅長等待別人慢慢猜。
* 面對不公平時會立即站出來；有領袖氣質，也會搶話。
* 不是每次情緒激動都失去判斷。

## 4.2 真正欲望

潔西卡真正想要：

1. **自己決定承擔什麼風險。**
2. **被視為完整戰士，而非家世、能力或性別的附屬品。**
3. **擁有不靠父親與母親傳奇建立的名字。**
4. **能在親密關係中被正面選擇，而不是被安撫或安置。**
5. **在成熟後仍保留張揚、火力與競爭，並學會更精確地使用它們。**
6. **證明領導不只是在最前面，也包括讓所有人活著回來。**

## 4.3 自尊

* 她能接受自己暫時不如雪奈；不能接受被當成沒有判斷的孩子、只因家世得到位置、被保護者替她決定哪些風險值得。
* 她需要區分尊嚴與面子：面子使她硬撐，尊嚴使她要求資訊、選擇與平等。
* 成熟不等於放棄驕傲，而是知道什麼值得堅持。

## 4.4 競爭

* 喜歡速度、力量、火力、訓練數據與清楚輸贏；競爭是她建立關係的方式之一。
