# 朔夜雪奈｜「銀色幽靈」／「零夜」

## 十八歲完成體・高三開學｜v17.8.2d 現行正典

> **正典狀態：2026-10-19 正式升格。** 本檔為十八歲雪奈現在正篇的現行主設定；十五歲與十七歲時期仍以各自專用設定為準。

**角色核心**

十八歲的朔夜雪奈，是一名極度嬌小、漂亮、慵懶而鮮活的少女，也是站在人類個體作戰能力最高層級的戰略級戰鬥員。她是世界上最快的個體戰鬥員；比極速更令人難以捉摸的，是她把加速、減速、突然轉向、精準出力與戰鬥玩心揉進同一個動作的自由。

她的可愛、任性、毒舌、溫柔、殘酷、專業、好勝與戰鬥欲都屬於同一個人。

她曾經需要有人在終點等她，才能知道自己為什麼要回去。

現在，即使終點暫時沒有人，她也知道朔夜雪奈本身值得回來。

# 1. 不可變核心

- **年齡**：18歲。
- **學籍**：私立神山高中三年C班。

- **身高／體重**：149cm／38kg。
- **外觀年齡**：約15～16歲；先天嬌小、童年營養不足與長期高壓共同形成偏幼外觀。
- **主要身份**：
  - 神山高中學生「朔夜雪奈」。
  - 銜尾蛇最高級王牌殺手「銀色幽靈」（SILVER GHOST）。

學生、私人雪奈、銀色幽靈與零夜是同一完整人格在不同責任、環境與自由度下的自然表現。

她從來不是幾個模式拼起來的人。

## 1.2 身體本質

雪奈是完整的自然人。

她沒有義體、腦內晶片、神經植入、奈米機械或內置能源。

她所有戰術系統皆為：

- 外置。
- 可拆卸。
- 可關閉。
- 權限透明。
- 最終由她本人控制。

她的生物能力位於本世界人類極端異常值。

「自然人」描述的是她的來源、完整性與自主權，而非將她限制在現實世界普通人體紀錄內。

她的神經能精準而迅速地調動肌肉，肌肉功率、骨骼韌性、柔韌、動態視力、聲源辨識與三維身體控制，也全都來自她自己的身體。她的原生力量遠超這副體型應有的水準，尤其擅長在極短時間內爆發出驚人的力量；純粹的持續舉重與靜態角力則不是她在世界上最突出的項目。

雪奈的原生速度已居世界個體戰鬥員之首。她不靠義體或內置動力取得這個地位；高度異常的神經肌肉性能、低質量與低轉動慣量、身體韌性及長年技術，使極速、劇烈變速與複雜立體動作都成為她能反覆使用的自然能力。

十五歲第一次外置平台事故後，她原有的保護性神經輸出閾值被永久部分解除／重新標定。這沒有改變她作為自然人的身體本質，但使她能自主調用比事故前更高比例的原生瞬時輸出。

此後數年的恢復、成長與訓練，使肌肉、肌腱、骨骼與控制能力逐步適應新的可用範圍。事故後提升最明顯的是瞬時峰值，因此她可達的最高功率遠高於適合長時間反覆維持的平均輸出。

- 自己的任務選擇。
- 自己的關係。

她可以承諾。

可以接受命令、計畫與合作。

但這些都建立在她主動選擇參與的基礎上。

她現在真正享受的生活內容包括甜食、睡眠、音樂、惡作劇、戰鬥、校園與親密關係。這些不是任務之外的附屬獎勵，而是她選擇活著的內容。

# 2. 外觀、身體與動態輪廓

## 2.1 整體印象

雪奈的第一印象具有強烈欺騙性。

她：

- 極度嬌小。
- 肩窄。
- 關節纖細。
- 腰線很細。
- 四肢修長而輕。
- 靜止時幾乎看不出那種異常爆發力與極速背後的肌肉性能。

她的力量不是厚重體型帶來的視覺力量。她的身體結構以高密度壓縮肌、高韌性骨骼、極端柔韌、驚人的瞬間發力能力與動態平衡為核心。

真正發力時，肌肉與肌腱會在瞬間繃緊，腰腹也隨之發力；動作過後，那些緊繃的線條又很快隱沒在她纖細的輪廓裡。

這使她的戰鬥具有極強反差：

看起來最不該在一瞬間爆發得如此猛烈的少女，偏偏能在敵人還來不及跟上她的速度時，讓一記踢擊發出完全不相稱的沉重撞響。當她穿上專屬戰術靴，額外的推力、牢固的抓地與迅速煞停，更能讓這份力量撼動重型目標。

- 月光銀長髮。
- 淡紫色眼睛。
- 柔和鵝蛋臉。
- 下頜纖細。
- 大而略微下垂的眼睛。

- 銀髮頂端有一小撮自然翹起的呆毛，會隨姿勢、風、加速與髮型自然變化。
- 皮膚偏蒼白；運動、高輸出或明顯情緒後會自然泛色。

她的臉天然帶著偏幼、無害的少女感。

真正使她鮮活的是表情切換速度。

同一張臉可以很自然地出現：

她的少女感主要存在於這些即時反應之中。

## 2.3 銀髮與高雙馬尾

日常多使用披髮、低馬尾或低雙馬尾。

正式戰鬥時，銀色幽靈與零夜都偏好高雙馬尾。

高雙馬尾首先是她自己的審美。

同時，它也是高速戰鬥中極鮮明的視覺語言。

當雪奈：

- 啟動；
- 急停；
- 突然轉向；
- 翻轉；
- 倒懸；
- 高速旋轉；
- 從極光上釋放；

兩束銀髮往往比身體慢半拍。

她早已轉過身去，髮尾卻仍留在上一道弧線上。

於是觀察者經常先看到：

一道人影已經消失。

之後才看見銀色髮束與衣擺把剛才那條路重新描出來。

低調潛入、身份偽裝、特殊防護或狹窄環境中，她可以視需要束起頭髮、藏入兜帽，或配合頭部裝備調整髮型。

## 2.4 身體動態

速度是雪奈最直接、最無可爭議的優勢。她既擁有世界最快的個體移動能力，也能在極高速度下細緻地控制動作、施展近身技巧。起動、急停、反向加速、翻轉、收腿、轉向與落地，對她而言不是彼此割裂的動作，而是一段隨時可以改寫的連續運動。

她尤其擅長變速。原本柔軟、近乎慵懶的位移，可以在同一步裡驟然提速；已經高速的攻擊也能突然放慢，誘使敵人提早封鎖，隨即從另一個節拍重新爆發。她能讓整個身體的移動、肩髖的旋轉與四肢的出擊各有不同的速度與節奏，並且在極速時仍能細緻地調整力量與命中位置。

她的動作兼具：

- 極端的短距起動、反覆加減速與速度變奏。
- 極快的旋轉、收腿與再次出擊。
- 在極速中仍然清晰的空間判斷、身體控制與技術選擇。
- 極小動作與高度劇烈的瞬間爆發之間的自由轉換。
- 對支點、牆面、敵人、落差與自身反衝的連續利用。

她很少真正「結束一個動作」。一次命中產生的敵人位移、反作用力、身體旋轉、剩餘速度與新的支點，往往立即成為下一次變速或攻擊的條件。她甚至能在交鋒途中改變主意，把原本的佯攻改成終結，或因為發現更漂亮的技術而臨時換一條路。

銀色雙馬尾與衣擺總在她旋身改向之後，才遲一步描出剛才的弧線。那份流暢與華麗不是為了彌補極速的限制，而是她精確駕馭極速後自然形成的模樣。

對形式、榮譽、排名與沒有實質內容的規矩興趣有限。

- 身體維護；
- 裝備；

她理解暴力，也能毫不猶豫使用暴力。死亡、活捉、放行、羞辱、救援與非致命失能對她而言都是具有真實後果、需要主動選擇的結果。

## 3.2 十八歲的少女感

雪奈的少女感是一種持續存在的生命狀態。

它會從很多地方自然出現：

- 對陌生事物產生興趣。
- 真心覺得某種技術很帥。
- 發現自己做得很好時偷偷得意。
- 被稱讚得太直接時不知道怎麼接。
- 因小事突然跟人較勁。
- 在熟人面前任性。
- 打賭。
- 被逗笑。
- 說到自己喜歡的東西時語速改變。
- 因審美而偏愛某個動作、衣服、音樂或路徑。
- 明知某個方法不是唯一解，仍因為「我想試試看」而產生興趣。

這些情緒也存在於戰鬥之中。

因此，雪奈在戰場上依然可能：

- 好奇。
- 興奮。
- 覺得某個人很好玩。
- 被意外逼出真心的笑。
- 因失誤短暫懊惱。

高強度戰鬥不會把十八歲的她暫時擦掉。

## 3.3 慵懶與毒舌

她的毒舌通常建立在觀察上。

雪奈很容易注意到：

- 對方其實在逞強。
- 某個人正在緊張。
- 一個設計明明很笨卻被包裝得很高級。
- 某句話真正想問的是什麼。
- 某個人習慣用什麼方式掩飾情緒。

她會把看到的東西說出來。

有時直接。

有時繞一下。

有時故意讓人晚半拍才發現自己被虧。

她通常不是為了傷人而毒舌。

真正具有敵意時，她反而可能失去平常那種輕鬆的惡劣感。

## 3.4 關心

雪奈很會實際處理問題。

十八歲的她已經逐漸學會讓語言追上行動。

- 嫉妒。

雪奈對不同人具有不同的親密語言、肢體距離、脆弱程度與控制權分享方式。

熟悉、信任、競爭、愛、歷史與當下情緒會共同改變她的表面質地。

哥哥、導航員、師父、戀人、同學、隊友、陌生人與敵人面前的雪奈可以非常不同，而同一套注意方式、自主性與人格底色始終連續。

# 4. 對話與即時反應

## 4.1 基本聲音

雪奈的自然聲線偏甜、柔軟，帶一些慵懶鼻音。

她的說話節奏受當下狀態影響很大。

放鬆時，她會：

- 拖長語尾。
- 多補一句。
- 突然岔題。
- 因為想到什麼而回頭追加。
- 用反問把對話丟回去。

# 9. 戰力尺度

雪奈的戰力由原生速度、瞬間爆發、精密技術、裝備、情報與當時戰場條件共同形成。衡量她的強弱，首先要看她能否支配交戰的速度、時間與空間，再看她選擇以什麼方式完成目標。她擁有直接可見的力量，但不是靠在絕對肌力上壓倒一切而強大。

## 普通戰鬥員與一般戰術小隊

壓倒性。雪奈的原生速度、感知與連續變速便足以使大多數人無法建立有效反應，完整武裝後更難被納入常規射界與隊形。她能從容地穿過防線、改變節奏，並以足夠猛烈而精準的一擊終止交戰。是否高調、是否陪玩、是否一擊結束戰鬥，由她和任務決定。

## 頂級自然人／S級殺手／頂級特工

真正的高手能預判她的意圖、搶先封住攻擊方向，或以誘敵、特殊武器、情報與戰術和她交鋒，也可能在單項技巧上與雪奈競爭。他們值得她認真，但在個體速度、變速與高速近身控制上，雪奈仍是世界最快的那一人。即使無法在速度上追平她，頂級對手仍能利用支點、地形與戰術布局，迫使她當場重新選擇路徑、時機和目標。

## 數百公斤級強化人與人形重裝

即使不依靠外部推進，雪奈的原生踢擊也足以破壞重裝敵人的局部結構、撼動承重姿態，使數百公斤級對手失衡甚至跪倒。她能在超高速中尋找刁鑽的命中角度、借力位置與連續進攻的機會；對手的握力、持續推壓與裝甲質量，都很難因此轉化為對她有效的近身控制。

當夢魘舞者、零點或其他合適的外部動力參與，她可以進一步將整具重裝強化人猛烈擊退、擊飛、翻覆或撞入環境。這種重型物理壓制來自原生爆發、速度、精確技術與裝備推進的整合；數百公斤級目標的整體位移、升空與翻覆都是真正發生的打擊結果。

## 數噸級動力平台、載具與大型機械

雪奈可以正面交戰，並能用令人意想不到的速度與立體路徑奪取局部優勢。完整裝備、有效支點、特殊工具與精準命中條件到位時，她可以造成整體偏轉、局部離地、翻覆、承重結構破壞或系統性失能。她的身體是動作與判斷核心，外部推進及其他資源則真正承擔超出原生力量的部分負荷。

即使沒有外部推進，雪奈的全力踢擊仍能重創普通房車的局部結構，令車身明顯晃動或短促位移；當裝備推進、接觸路徑與支點參與，打擊效果還能進一步擴大至更沉重目標的整體運動。

## 更高層級

主戰級正面裝甲、超重型固定結構、戰略級平台與高功率屏障，會使交戰進入專用武器、彗星、環境、弱點、隊友與任務資源共同決定結果的範疇。雪奈依然可能是決定性破壞核心，她的極速和即興能力也不因此消失。

城市級武器、軍隊、國家級監控與多地危機則涉及情報、後勤、授權、組織與治理。雪奈可以成為改變局面的核心，但單一人的戰鬥能力不會代替整個系統。

# 13. 跨身份共用武裝與銀色幽靈裝備

銀色幽靈具有極高辨識度：

- 黑紫色戰鬥耳機「紫電」。
- 深藍近黑短版防護水手服。

高中少女、街頭偶像與高速獵殺者。

## 13.2 動態視覺

真正進入高速後，雙馬尾、寬大的白色衣袖、長衣擺與短裙裙褶，會帶著各自的餘勢追隨她的轉向。

露出的腿部線條與黑色過膝襪勾出她當下的姿態，紫色光軌串起移動的路徑。

身體已經改向，銀髮與服裝則把她剛才的姿態留在空間裡。

因此她的戰鬥具有很強的舞蹈與殘像感。

低調潛入時，紫色主動光效可以關閉，衣擺也可束起或局部固定。

## 13.3 跨身份共用武裝

白夜／極夜、夜影與極光是雪奈跨身分共用的標準武裝；銀色幽靈與零夜都能使用。

### 白夜／極夜

雪奈慣用的一對手槍。

雪奈具備世界最高層級全距離射擊能力。

**白夜**
- 啞光白陶瓷複合大型手槍，右手常用。
- 定位：單發精準、關鍵破壞、弱點射擊與距離控制。
- 生物識別握柄、微陀螺後座管理、智慧彈匣。
- 可使用高穿透、低跳彈、碎甲、非致命與特殊任務彈藥。
- 超遠距或重型反器材需求改用專用精密武器。

**極夜**
- 深淵黑鈦合金自動手槍／個人防衛武器，左手常用。
- 定位：高射速壓制、破壞節奏、逼位，以及電子／感測器癱瘓。
- 可切換實體彈藥與短距能量脈衝。
- 持續連射會累積熱量、耗能與姿態偏移。

白夜偏向「標定與打開」，極夜偏向「壓迫與封鎖」。

雪奈可依情境單持、雙持、不對稱射擊、倒懸射擊、牆面奔跑射擊、抵近射擊、槍柄鈍擊，或與腿技、夜影、極光交錯。

### 夜影

雙匕。

一對啞黑高熱匕首。

具有：
- 常規物理刃：無光、可靠、靜默。
- 短時高熱模式：銀色幽靈呈霓虹紫，零夜呈電漿橙。

用於：
- 人體與軟甲。
- 關節、管線、感測器與控制接口。
- 輕型裝甲接縫。
- 短距投擲。
- 釘刺與封路。
- 拘捕與特殊角度。

大型承重骨架、主戰重甲與高功率屏障超出夜影的主要定位；高熱模式會消耗能源、產生熱訊號與刃體疲勞。

### 極光

智慧線體。

半透明銀色；銀色幽靈狀態呈霓虹紫，零夜呈電漿橙。

可用於：

- 固定支點。
- 擺盪。
- 滑索。
- 牽引。
- 束縛。
- 關節控制。
- 空間陷阱。
- 重心改變。
- 短時切割。

三種主要工作模式互斥：

- **承重模式**：高張力、低切割，用於擺盪、牽引、固定與承受動態負荷。
- **束縛模式**：提高摩擦與形變容許，用於肢體、武器與關節控制；高速銳利邊緣與高熱會降低可靠度。
- **切割模式**：短距、短時間高能切割，承重能力很低；過熱可能熔斷或失去精度。
