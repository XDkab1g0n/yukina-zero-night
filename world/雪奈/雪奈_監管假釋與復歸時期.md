# 朔夜雪奈｜監管假釋與復歸時期

> **時期定位**：十七至十八歲，煉獄坩堝、升任准尉與404號房之後，正式赦免之前。前接《雪奈_喪鐘時期.md》，後接根目錄《current_canon.md》。
> **核心印象**：銀色幽靈重新出現在新東京的街頭，終於可以回到自己的住處、接單、上學、吃甜點；軍方的執行環卻仍戴在她頸上。她在重新接觸人群的過程中，從一個被迫服役、依靠暴力填補空洞的人，逐漸成為教官、搭檔，以及願意為自己的明天而活的朔夜雪奈。
> **時間尺度**：以事件先後與因果為準。假釋、教官工作、軍方任務、點數累積及記憶調查可並行；未鎖定精確月份。奏此時約十四至十五歲，現行主線十五歲、高一。

## 1. 身份與假釋

煉獄坩堝後，雪奈以准尉、臨戰協調官的身份持續取得戰功及制度信用。曾於天堂之門獲救、後升少佐的竹村提供有限的制度內支持，銜尾蛇與軍方亦進行協商。軍方同意她離開基地，在持續監管下恢復銀色幽靈的地下工作，以處理地下威脅並保持其戰略價值。這項特殊安排通稱「監管假釋」。

她仍是被判死刑、暫緩執行的喪鐘作戰人員，軍方編號X-00。假釋並未達成點數赦免，執行環、強制任務與軍方管制仍然有效。

| 面向 | 假釋期間 |
|---|---|
| 居住與私人時間 | 基地外私人安全屋，可自行安排生活、購物、休息與恢復部分學校生活 |
| 地下工作 | 重新以銀色幽靈身份接受銜尾蛇委託，遵守其契約與中立規則 |
| 軍方工作 | 指定的極密及高危任務仍屬強制，雪奈通常獨自執行；奏不是軍方任務成員 |
| 點數 | 軍方認列的任務繼續累積赦免點數；私人委託不自動計入 |
| 執行環 | 保留喪鐘時期的定位、生命徵象、通訊、強制失能及終止權限 |
| 情報 | 軍方要求銜尾蛇維持白噪相關情報隔離，不主動揭露雪人歷史或協助解除封鎖 |
| 地位 | 准尉及既有軍方權限是制度工具；假釋待遇可被撤回，正式赦免仍是可能達成的最高目標 |

銜尾蛇並未取得執行環的控制權。巖本與鬼婆希望把雪奈帶回熟悉的環境，讓她重新接觸有生活、有選擇的世界。雪奈則把新的空間當成自己的生活與工作，也持續調查白噪留下的矛盾。

## 2. 外觀、能力與生活

她仍是149cm、38kg的自然人，保有喪鐘累積的全領域技術、戰場經驗及極端輸出控制。白噪隔離自傳記憶及情感索引，未刪除人格、知識與技能。暴力渴求、過量追擊、低自我保存權重及情感空洞會隨情境浮現，並逐步在生活與人際關係中鬆動。

銀色幽靈的裝備逐步恢復為適合地下委託的個人配置；軍方專屬平台「虛像」及其武器依授權使用。這個時期的具體裝備迭代、取得時間與各任務配置留給前傳確立。外觀沿銀色幽靈的銀髮、紫瞳與個人風格發展；在學校或日常外出時可用圍巾等普通衣物遮住執行環。正式赦免後才取下軍方拘束裝置，現行個人黑色頸環「樞紐」是另一件自主裝備。

基地王牌時期她已累積十萬點、享受充裕的私人生活，卻未把減刑當作主要人生目標。士官學校曾讓她短暫體驗正常生活；監管假釋則讓她有機會自行安排基地外的人生。這些經驗與白噪的鬆動共同促使她逐漸真心希望取得自由。

假釋初期，她獨居於臨時安全屋，生活凌亂，常以甜食、遊戲、睡眠和接單度過時間。曾經熟悉的普通生活重新出現，但尚未完全恢復當年的活潑。隨著教官工作與奏進入生活，她開始有非任務的安排與期待。舊宅曾遭轟炸；現行朔夜宅邸的復建與入住時間留待具體前傳確立。

## 3. 教官篇

### 3.1 巖本與鬼婆的安排

巖本先安排雪奈指導成年殺手，讓她重新練習在無須殺死對手的情境中運用卓越技術，隨後由她擔任一屆殺手訓練營的首席教官，巖本仍是銜尾蛇總教官，鬼婆佐藤仍負責培訓中心及人員管理。這項安排兼有培養新人的目的，也讓雪奈重新面對自己早年經歷過的環境。

初期雪奈極端嚴苛。她具有精準控制力，卻習慣以喪鐘的高壓標準評價別人，也可能漠視學員受苦。她逐漸在那些孩子身上看見自己的過去，開始把技術精度、恢復、生存與彼此協作看得比單純淘汰更重要。她的訓練仍然嚴格，但不再以折磨本身為成就。巖本曾經教給她的保存身體與控制力量的原則，開始透過她自己的教學重新出現。

### 3.2 No.012

奏是此屆學員之一，編號No.012。她已有地下培訓基礎及出色的潛行、近身控制與精密操作天賦，對環境缺乏信任，習慣把受傷、沉默與有用當成生存條件。雪奈注意到她的潛力，也在她身上看見以前的自己。

訓練中，雪奈曾把自己的布丁分給奏。這個小小的善意呼應九歲時鬼婆曾給雪奈布丁的往事；在完整記憶尚未接回之前，她已經開始把曾經得到的照顧傳給另一個人。奏由畏懼、競爭與求生逐步走向對教官的信任與崇拜。

該屆訓練結束時有一百名學員存活，前三名取得直接準備出道資格，其餘進入高級班；No.012名列第一，正式以貓屋敷奏、「黑貓」的身份進入地下委託體系。死亡與淘汰的具體數字分布、考核細節及訓練週期留待前傳描寫。

## 4. 從師徒到搭檔

### 4.1 新人小隊

雪奈帶領前三名新人執行首次委託。奏、鐵塚剛（重錘）、風間徹（聽風者）在此共同出道；任務的重大傷亡使重錘戰死，雪奈為了保護奏而重傷，奏帶著失去戰鬥能力的雪奈撤離。具體任務、敵人、傷勢與撤離場景由前傳確立。

奏第一次切身明白自己崇拜的最強者也會受傷，也可能需要她的幫助。雪奈則認為自己的高危工作不適合繼續帶新人承擔，解散這個新人小隊，要求奏與風間獨立成長。這既是保護，也讓奏一度將變強視為重新站到雪奈身旁的唯一方法。

### 4.2 王牌選拔

奏獨立累積委託實績與信用，取得王牌選拔的資格。雪奈親自參與對她的能力評估，壓倒性擊敗她，卻承認奏已經取得足以成為S級的技術與成長。選拔對戰是評估之一，資格仍依銜尾蛇的任務實績、獨立行動、信用與責任標準成立。

兩人接受組織安排的階段性雙人搭檔工作。雪奈要求奏不要再只把自己視為教官、不可違抗的上級或崇拜對象，而要在任務中以有獨立判斷的搭檔與她並肩。奏改稱她為「雪奈姐」。她們在技術上仍可有師徒關係，在契約與合作中則以搭檔相處。

## 5. 雙人組合與生活重建

完成組隊後的第一個任務，奏主動要求與雪奈一起生活並照顧她。雪奈起初不習慣有人介入自己的私人空間，最後同意。奏擅長料理與整理，雪奈則在生活之外持續指導她戰鬥與課業；兩人逐漸建立共同用餐、休息、訓練及校園生活的日常。

這段生活與地下工作彼此交錯。奏仰慕雪奈，也因雪奈的傷勢與軍方強制委託而焦慮。她希望自己能替雪奈分擔風險，卻曾在能力、資格或準備不足時擅自承接高危任務，導致自己陷入危機、雪奈負傷救援，並因事件而被降回A級。奏密集承接A級委託，重新取得S級資格，卻仍不顧傷勢地工作與鍛鍊。雪奈勸阻無效，兩人激烈爭吵，奏離家；其後奏重傷倒在雪奈住處前，雪奈親自照顧她，兩人共同養傷並逐漸修復關係。

雪奈在尚未完全取回記憶時，已站到了當年雪人阻止她為力量不顧一切的相似位置。她開始理解照顧不是替別人承擔全部風險，也不是任由對方把自己消耗殆盡。奏則逐步明白，即使沒有完成任務或證明有用，她仍能被雪奈留下。

關係修復後，階段性雙人安排終止，兩人恢復各自獨立承接委託的常態。奏後來取得雪奈住處附近的獨立安全屋，與雪奈共同生活由安排逐漸轉為自願選擇；現行安全屋與朔夜宅邸相距約50米。兩人仍會共同出任務、對練與照顧彼此。具體入學行政、戀愛關係成立時點及住處遷移先後留待前傳鎖定；現在篇維持雪奈高三、奏高一。

## 6. 記憶整合與赦免

假釋期間，雪奈延續基地內對白噪的調查。舊場所、巖本與鬼婆、照顧學員的經歷及與奏的共同生活，使她逐漸建立新的情感與未來期待。這些經驗與她主動取回過去資料的努力並行。

她最終找到雪人留下的錄影留言，聽見哥哥希望她好好活下去的心願。錄影是最後的情感連接點，讓逐步回流的記憶與當下的選擇匯合。她接受雪人的死亡，承認修羅、喪鐘及假釋時期皆屬於自己，也開始肯定即使哥哥不在，她仍然值得活下去。這段整合不抹除她曾經做過的選擇；她的玩心、甜食喜好、戰鬥欲、專業與對人的關心，都重新找到可以共存的生活。

記憶整合使她更能保存自己、穩定地完成高難度軍方工作。她持續累積點數，終於成為第一個達成天文數字赦免門檻的死刑犯作戰人員。軍方正式赦免她、解除並取下執行環；為留住最高戰力，防衛省改以契約與她合作。她堅持保有銀色幽靈的地下身份、私人生活及自主權，後來零夜的自主契約由此成立；最初官方行動代號為00（Double O），其後加入八咫烏並親選零夜為正式代號。詳見《雪奈_八咫烏早期與零夜命名.md》。

## 7. 時期差異與寫作取用

| 階段 | 人物重心 | 法律及控制狀態 |
|---|---|---|
| 基地喪鐘 | 病理化、戰鬥成癮、反抗與制度內求生 | 死刑拘束、基地生活 |
| 假釋初段 | 回到城市、重新工作、教官生涯 | 死刑暫緩、基地外監管 |
| 假釋中段 | 奏的成長、師徒到搭檔、共同生活 | 執行環與強制軍方任務仍在 |
| 假釋後段 | 記憶整合、選擇未來、達成點數 | 仍受拘束，直至正式赦免 |
| 正式赦免後 | 自主生活、銀色幽靈與初期00／後來零夜 | 自由主體、契約合作 |

對應時期的裝備、關係、心理與所知依當時進度描寫。雪奈初期仍可能殘酷、躁進、毒舌或冷淡，也會在教學、甜食、遊戲、日常鬥嘴與關心他人中逐漸展現活力。她不是在某個瞬間突然換回另一個人格；教官、黑貓搭檔與後來的零夜都屬於同一段人生。

## 8. 事件與未鎖定細節

核心事件的相對順序已確立：准尉與404號房 → 監管假釋 → 成年學員指導 → 新人訓練營與No.012 → 首次委託及分離 → 奏獨立成長與S級選拔 → 組隊及共同生活 → 高危委託、降級與恢復S級 → 爭吵、離家與關係修復 → 雪人留言與記憶整合 → 點數赦免 → 自主契約與00 → 八咫烏及零夜命名。軍方任務、調查、點數累積與生活重建在其中交錯。

尚待具體化的是各階段精確月份、竹村的具體協助程序、任務細節、教官考核、校園行政、舊宅復建及契約正式簽署場景。舊稿中的固定半年訓練及三個月最終軍方任務並不直接鎖定為現行時長。
