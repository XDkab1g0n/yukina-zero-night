# 1. 前置背景與時期階段

## 1.1 前置事件：修羅與被捕

* 雪人遭神秘勢力調虎離山炸死後，雪奈進入「修羅」狀態：她保有完整記憶、清晰目標與長期追蹤規劃能力，主動捨棄睡眠、甜食、關係、回程與未來，沿責任鏈精確追殺並處刑幕後規劃者。
* 完成主要復仇並與軍警、特種部隊長期交戰後，她並非技術下滑，而是身體重傷、能源與補給耗盡、精神長期單一目的過載，又在復仇完成後失去繼續支撐修羅的唯一目標，最終在多重國家級資源圍捕下被消耗至失能而被捕。
* **秘密法庭審判時她仍保有哥哥的記憶**，身上留有重傷；死刑判決成立後，軍方因其戰略價值將她移交喪鐘，於深淵迴廊執行「白噪程序」與執行環安裝。

| 子階段 | 身份、空間與裝備 | 心理、生活與關係 | 能力與指揮狀態 |
|---|---|---|---|

# 2. 關鍵事件脈絡

## 2.1 從死刑犯到「幽靈」

* 初入深淵迴廊 B-17 時，醫療與營養僅維持基本服役，舊腹傷與拘捕重傷未癒，配發的黑色戰鬥膠衣、戰術夾克與軍靴老舊且不合身，昔日個人武裝、情報網與生活全遭剝奪。
* 最初送葬者看她嬌小重傷、不信任這個死刑犯新人，將高危工作推給她且剋扣待遇；衝突招致執行環懲戒、禁閉與扣點。合作徹底惡化後，葛城改派她單獨承擔極低成功率的孤狼勤務，她帶傷且用劣質裝備屢次完成。
* 定期體檢讓葛城確認她的恢復力與極端身體控制皆源於自然人天賦與過往實戰（含十五歲事故後神經基線），而非軍方改造；為免破壞她的精密習慣，葛城決定不施作永久植入，改為改善醫療與營養，並正式改以「幽靈」稱呼（X-00 仍為正式管理編號）。
* 她用早期單兵獎勵買下第一個真正的布丁、好好洗一次澡，以及第一隻小型鯊魚玩偶。玩偶後來遭其他成員搶走弄壞，雪奈奪回後親手縫補並保留下來，命名為「一號機」。

## 2.2 天堂之門與新任隊長挫折

* 重新歸建送葬者（鐵砧、壁壘、釘子、毒蛇、幽靈）後，執行新宿隔離區百貨舊址 S 級營救「天堂之門」，營救被困正規軍第三中隊殘部。雪奈扛下主力交火與破障，倖存正規軍全數獲救，但送葬者隊長鐵砧與壁壘戰死。
* 獲救的正規軍指揮官**竹村中尉**代表全隊向她鄭重道謝。這份不帶點數評價或命令意味的感謝，成為她喪鐘早年少見的「行動對他人具真實意義」的刻痕，也埋下竹村日後晉升少佐、在煉獄坩堝與假釋階段從正規軍體系提供有限協助的伏線。
* 戰後獲大量點數與短暫休假，購入大型鯊魚玩偶「二號機」、漫畫、掌機與甜食。葛城原欲由釘子接任隊長，釘子主動讓位給幽靈、自任副手。
* 然而初任隊長的雪奈雖讀得懂全局，卻不懂如何讓速度與水準遠遜於自己的隊友發揮作用。隊友跟不上時她直接接手硬扛，結果補入的獵犬與鬣蜥仍在高強度任務中戰死，她自己也因長期過度負荷與舊傷反覆重傷倒下。釘子在此期間開始留意她的傷勢與疲勞，將隱晦的關心藏在實務支援與善後裡。

## 2.3 養傷與正規軍士官學校

* 累積傷勢倒下後，葛城與軍方察覺「讓頂尖單兵硬撐全隊」正在浪費戰略資產，暫由他人代管送葬者，安排雪奈在養傷期間以掩護身分進入正規軍士官學校，接受正式戰術指揮、兵種協同、部隊編組與後勤課程（受監管公務進修，非基地外私人假釋，精確週期未定）。
* 她嘴上嫌棄教條冗長，實則憑高智力與實戰直覺迅速吸收正規軍事架構，滿分結業。更重要的是，短暫的正常食堂、課堂競爭與普通同儕互動，讓她第一次在喪鐘體制裡嘗到「沒有每分鐘都在流血」的規律日常，並真正學會「部隊不是拖油瓶，而是能替自己分擔戰場的人」。

# 3. 外觀、服裝與當期武裝

## 3.1 外觀狀態（前期特徵）

* **收容與入隊初期**：營養與照護嚴重不足，銀白長髮乾燥分岔、身形更加削瘦蒼白，臉上與四肢帶著修羅與拘捕留下的新舊傷與繃帶；眼神低反應、戒備度極高。
* **孤狼中後期至軍校**：隨醫療、飲食與沐浴改善，體能與髮質逐步回復，毒舌與不耐表情增多；綁高雙馬尾出勤，休整時披散或隨便一紮。頸部始終配戴啞光黑**執行環**（低亮度紅燈）。

# 4. 前期心理切面與聲線矩陣

## 4.1 當期心理刻度（相較中後期）

* **暴力成癮尚處「止痛 → 啟動 → 初期亢奮」階段**：
  * 入隊最初的沉默不是麻木，而是重傷保存體力＋拒絕配合＋冷眼觀察監控盲點。
  * 進入孤狼期後，高危單兵交火讓她第一次發現「全力戰鬥時，胸口那塊白噪造成的空洞會安靜下來」——暴力從單純完成命令轉變成主動尋求的感官止痛與清醒感。
  * 尚未發展出准尉後期那種極端高耐受的長時失速狂犬狀態，但高壓力、被挑釁或被執行環電擊後，已會出現明顯的過量追擊、冷笑與惡意合規。
* **對隊友的態度處於「敵對／視作累贅 → 隱晦在意」過渡**：
  * 最初將隊友視作會拖慢節奏或出賣自己的風險源；天堂之門後，鐵砧與壁壘之死、竹村的道謝與釘子的讓位讓她第一次意識到「隊友不是背景板」，卻仍只懂得用「自己多扛一點」和尖銳毒舌（「別死在我射線上」）表達。
* **對權威的反抗更原始直接**：常以低反應沉默、極限字面服從、拆解室內物件與偶爾尖銳頂嘴試探葛城底線，並已開始偷偷紀錄執行環延遲與守衛輪班。

|---|---|---|---|

# 5. 當期戰鬥能力與指揮盲區

* **單兵實力已居世界頂尖**：即使只有劣質膠衣與普通步槍，她依舊能憑幽靈舞步、三維空間預判與常規六類踢技（底盤 §4.4）在數秒內拆解整支武裝小隊；面對強化人與數百公斤重裝，透過槍刃開弱點、地形加速與**無推進版後翻雙足上轟**，仍能打出令人震懾的位移與結構破壞（但不具後期嵐足與極限螺旋飛踢的數噸級推力放大）。
* **反作用力與傷勢代價極高**：初期無高階護具與吸能系統，加上舊腹傷與拘捕傷未癒，高強度踢擊與連續變向直接反映為足踝腫痛、舊傷滲血與體力見底。
* **指揮盲區（本檔核心成長線）**：她讀戰場的速度遠快於隊員能聽懂的速度。新任隊長初期只會下達「跟不上就閃開」式的單兵指令，沒給重裝、火力與支援位留出合理節奏；直到獵犬、鬣蜥戰死與自己倒下、經士官學校系統化訓練後，才跨出從「單兵怪物」到「真正指揮官」的第一步。

# 6. 人物關係與 B-17 早期日常

## 6.1 本期關鍵人物

* **葛城十藏**：由「當高危消耗品隨手丟進火線」→「孤狼戰績震驚，體檢確認自然人潛力、改稱幽靈並升級醫療營養」→「察覺她帶隊硬撐太浪費資源，送去士官學校」。兩人已開始建立高智商試探與鬥嘴，但控制與威懾仍赤裸直接。
* **鐵砧與壁壘**：最初不信任這個嬌小死刑犯，卻在天堂之門中並肩死守至戰死；他們的陣亡讓雪奈第一次在喪鐘體會到「同隊者活著或死去的重量」。
* **釘子**：最初送葬者裡最冷靜務實的老兵；天堂之門後看清幽靈的戰場價值，主動讓出隊長位自任副手，在新任隊長挫折期悄悄幫她收尾、遞藥與提醒體力底線。
* **毒蛇**：早期已入隊的滲透／機動好手，與雪奈同屬高自主性類型，初期互相試探防備，隨實戰逐步建立基本信任。
* **竹村（當時中尉）**：天堂之門中獲救的正規軍指揮官，稱她「幽靈小姐」，是少數不把她當怪物或死刑犯、而是作為救命戰友鄭重致謝的體制內軍人。

## 6.2 B-17 早期監禁室日常

初期的 B-17 狹窄、強光常亮、固定床鋪、物品高度受限且無真正死角。雪奈在物資匱乏與高壓監視下形成獨特的反制日常：
* 以長時間睡眠拒絕審訊與無意義對話。
* 聽腳步聲與換班頻率，精確計算守衛輪值與攝影機轉向節奏。
* 故意調整呼吸與心率，餵給監控系統錯誤的生理基線資料。
* 暗中拆解並重組手邊可用小物件；把難得換來的糖紙與布丁包裝摺成標記時間與訊號週期的記號。
* 孤狼期點數增加後，最先改善的不是武器，而是**真正的布丁、熱水澡，以及那隻被弄壞又親手縫好的小鯊魚「一號機」**；天堂之門後才添置巨型「二號機」與掌機、漫畫，開啟 B-17 向「小窩」演變的第一步。

## 7.1 當期額外弱點（疊加底盤 §5）
