## 1.3 關鍵事件脈絡

### 從死刑犯到「幽靈」
移交喪鐘後，雪奈帶著修羅與拘捕留下的重傷住進深淵迴廊 B-17。起初醫療與營養僅維持基本服役，配發裝備老舊且未必合身，個人武裝與情報網全數被剝奪。最初的送葬者（鐵砧、壁壘、釘子、毒蛇；入隊測試另有未留任的蟑螂）把這名嬌小重傷的新人視為累贅，常派她做高危工作並壓低點數分配；隊內衝突招致執行環懲戒、禁閉與扣點。合作惡化後，葛城改派她單獨執行成功率極低的高危任務。她帶傷、裝備劣質仍屢次完成，迫使葛城透過定期檢查確認其純自然人身體與事故後的異常恢復及爆發力。葛城刻意不進行永久強化改造（以免毀掉她精密的身體控制與成熟習慣），改為提供良好醫療營養並測試她恢復健康後的常規戰力，結果遠超預期，從此改用呼號「幽靈」。

她用單兵點數買到真正布丁、充分沐浴與第一隻小型鯊魚抱枕；該玩偶曾被其他成員奪走弄壞，她取回後親手縫補並一直保留，成為「一號機」。毒舌、戲謔、對甜食與玩偶的喜愛重新活躍；她會嫌棄配給、嘲笑葛城，不必把每次娛樂都當成反監控。

### 天堂之門與新任隊長挫折
重編入送葬者後，參與 S 級營救任務「天堂之門」：於新宿隔離區百貨公司舊址營救受困的正規軍第三中隊殘部。雪奈承擔主要戰鬥負荷，倖存士兵全數獲救，但初代隊長鐵砧與隊員壁壘戰死。獲救的竹村中尉代表部隊向她鄭重道謝、稱她「幽靈小姐」——這份不牽涉點數與評級的感謝，使她第一次在喪鐘中重新感覺到自己的行動對他人具有意義。戰後她獲大量點數與休假，購入大型鯊魚「二號機」、漫畫與遊戲機。

原獲葛城指派接任隊長的釘子基於能力認可主動讓位，改任副隊長。然而初任隊長的雪奈尚不熟悉讓能力與速度遠不如自己的隊員協同：隊友跟不上時她便直接接手包辦，補入的獵犬與鬣蜥對她心存不服並於後續任務戰死，她自己也因反覆過度負荷而多次重傷。釘子看過她逞強負傷後，逐漸形成極為隱晦的保護欲，以實際支援與盯防狀態表達。

### 養傷與正規軍士官學校
一次累積傷勢與疲勞令雪奈倒下後，軍方暫將小隊交由他人代管（身分未定），安排她在養傷期間以掩護身分進入正規軍士官學校，修習戰術指揮、兵種協同、組織與後勤。她嘴上嫌棄教條冗長，卻憑過人理解力與實戰經驗迅速吸收，結業測驗取得滿分。軍校的規律作息、正常食堂與從輕視轉為認可的同儕（也有人在她養傷時照顧她）讓她短暫體驗到久違的正常生活；此階段仍屬受監管軍方進修，非基地外私人自由。

# 3. 白噪程序與暴力成癮形成

## 3.1 「白噪程序」與記憶回聲
軍方未實施腦葉切除，而是以藥物干預記憶再鞏固、睡眠與感官剝奪、重複敘事覆寫、非植入式神經刺激與資訊封鎖，構成多層「自傳性記憶與情感索引隔離」。
* **記得的事**：知道自己叫「朔夜雪奈」、檔案裡有個已死亡的哥哥「朔夜雪人」，能讀懂任務與醫療資料。
* **被奪走的事**：情感索引、自傳連續性、關係歸屬與未來延伸——「哥哥死了」只像一條別人的資料，無法連回「那是我的人生」。
* **身體記憶與記憶回聲**：消毒水與乾淨洗衣味、特定檢查傷口的節奏、特定布丁口味、簡短具體的導航語句、抱緊鯊魚玩偶，以及戰後下意識尋找出口與「終點應在的人」，皆可能引發短暫卡頓、呼吸變化、無原因落淚、憤怒或分析性懷疑；但不固定導致戰場失能或崩潰。

## 3.2 暴力成癮的形成與四層高烈度狀態
情感空洞、長期剝奪與外部強制，使暴力從最初的感官噪音逐步發展成成癮性正回饋循環：**渴求 → 出擊前躁動 → 高強度接觸 → 情緒抬升 → 追求更近更重刺激與恐懼回饋 → 停止條件延後 → 戰後墜落與空洞反撲**。
* **四層高烈度狀態**（同一場戰鬥可高速切換）：
  1. **臨床殲滅**：最短路徑、最少動作、精準拆解目標，是她所有狂氣的技術底色。
  2. **暴力亢奮**：第一個有重量的撞擊或自身疼痛就能讓眼神亮起、笑聲浮現，主動壓近安全距離。
  3. **殘虐 binge／狂犬**：高渴求、項圈懲戒或記憶回聲觸發下，明知一擊可結束卻故意留手延後終止點，欣賞敵人恐懼、求饒或重新舉槍（「起來。」「再一次。」「不要這麼快壞掉。」），同時戰術判讀依然精準在線。
  4. **控制報復**：字面服從命令，卻刻意選擇讓軍方承受最大財務、設施或政治代價的完成方式。
* **甜食、玩偶與照顧滲漏**：布丁、巧克力與一號機／二號機既是她的真實喜好，也在低潮與驚醒時帶來安定。她仍會拖走傷員、避開平民、替正規軍開撤離線，初期多以尖銳效率語言包裝（「屍體擋路」「你們活著比較方便」）。

# 4. 當期戰鬥能力與邊界

## 4.1 全領域單兵實力
白噪未削弱任何既有技能：她從入隊起即具備世界頂尖的**三維近戰（雙腿踢技為主、槍刀線輔）、全距離射擊、潛入與反追獵、軍用級現場駭客與電子戰、爆破、情報分析與戰場急救**。差異在於初期受限於重傷、營養不足與劣質裝備；孤狼恢復後，以普通軍規武裝便已展現驚人戰力。

## 4.2 踢技主導與常規裝備尺度
* **幽靈舞步**：不規則重心微移、高速折線、牆面與敵體借力、旋轉卸力；不靠踩踏空氣或憑空飛行。
* **常規踢技與後翻雙足上轟**：乾淨主力踢擊足以直接令普通戰鬥員離地失能、撼動數百公斤級重裝；面對數噸級目標與重裝甲時，因缺少外置推進與高頻粒子刃，須更仰賴高速路徑、下側軸線、常規爆破、射擊接縫與環境支點，且足踝、膝髖與舊腹傷的反衝代價極為直接。
* **螺旋飛踢**：可由衝刺、蹬牆、常規線索擺盪或高處墜落疊加初速施展，破壞力高但回收與落地風險大，過量使用易直接傷及下肢與舊腹傷。
* **指揮邊界（本階段專屬限制）**：新任隊長時期她的戰場判讀極快，但常忽略普通隊員的移動速度、火力銜接與心理負荷，導致戰術變成「一個人打整場、隊友負責善後卻仍出現傷亡」；直到士官學校結業，這項短板才真正補齊。
