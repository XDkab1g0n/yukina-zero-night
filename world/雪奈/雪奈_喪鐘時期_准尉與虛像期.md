# 2. 實驗性單兵作戰平台「虛像」

## 2.1 系統定位與控制矛盾
「虛像」是軍方由緒方博士主導、專為 X-00 建立的全距離火力、動作放大與數據採集平台。軍方既想最大化她的戰略戰力，又害怕她取得完整權限，因此全模組內建**遠端遙測、功率上限、軍方簽章、斷電權限、地理圍欄與數據回傳**。她能靠虛像打出逼近後期成熟裝備的峰值破壞，也始終在尋找繞過與逆向控制的方法。

## 2.2 視覺與數據背心
* **配色與結構**：啞黑、深灰、灰白主體＋**冷霓虹藍**光效＋頸部紅色執行環。含無框／半框多光譜戰術目鏡、骨傳導通訊、全覆式黑色壓力作戰服、深灰模組化短背心、灰白短袖戰術夾克、胸背／脊柱／肩部輕量陶瓷複合護板、高腰黑色戰術長褲、護膝與嵐足。
* **生理與數據背心**：即時監測生命徵象、肌電、姿態、反作用力、熱量、能源與情緒可疑指標（能看數據，不能讀心），並向幻影、鳴神、嵐足、蛛絲與目鏡供能；斷電會令裝備降級，雪奈本人仍是世界頂尖自然人戰士。

## 2.3 五大核心模組

### 幻影／模組化能量步槍
* 提供三種構型：**緊湊構型**（室內／載具高射速脈衝，升溫快）、**突擊構型**（中距均衡主力）、**狙擊構型**（延長槍管與聚能反器材，完整轉換需時間與零件，高功率需冷卻與穩定）。
* **軍方限制與反制**：彈道與目標全回傳、特定友軍／設施具軟體鎖、遠端可降功率；雪奈能以機械備援、手動射擊與改寫部分識別繞過限制。

### 鳴神／高頻粒子軍刀
* 脇差至短軍刀長度，冷藍粒子場，分**低功率**（無聲切割纜線與精密入口）、**中功率**（戰術護甲、義體關節與接縫）、**高功率**（重甲、加固門、能源核心與短時結構拆解）。
* 兼具精密刺入、滑切、反手拆解與高功率破壞；過量破壞常是對控制者的報復或情緒宣洩，而非只會重劈。

### 蛛絲／三線匣線體系統
非萬能單分子線，分三種耗材線匣（由軍方配給，她會偷藏短段備援）：
* **承重索**：較粗高韌，供滑索、擺盪、牽引與撤離。
* **束縛索**：高摩擦可形變，供關節、武器與活捉控制。
* **切割絲**：極細高張力短距，供陷阱、纜線與裝甲接縫，不可承受人體擺盪，易受高熱與強磁影響。

### 嵐足／磁浮與矢量戰術靴
* 提供磁性吸附與排斥、短促矢量推進、爆發起步、牆面與天花板機動、空中姿態修正、落地緩衝與踢擊動能放大；能達成短距「偽飛行」與銳角變向，但**不具備穩定持續懸浮**，亦缺成熟的重錨與大型目標制動架構。
* **風險與逆向修改**：高耗能、易受電磁干擾、強制斷電時可能在半空或牆面失足；反作用力保護不完全（軍方甚至刻意把部分極限當測試數據），極易由足踝、膝髖、核心與舊腹傷替系統付帳。雪奈持續自行修改噴口節奏、吸附延遲、安全上限與手動備援。

### 目鏡與電子戰
* 多光譜視覺（熱／低光／偏振／能量）、威脅標記、彈道與結構分析、平民與撤離路徑、本地網路滲透與載具／無人機接口。
* 軍方設外網白名單、指令審計、封包監控與地理圍欄；雪奈以離線實體接口、隱蔽旁路、藏入合法遙測的惡意程式與敵網中繼反制。

# 4. 戰鬥能力與跨隊指揮

## 4.1 踢技主導與虛像複合層級
* **第一主武器**：雙腿與踢技，由**嵐足**進一步放大動能、變向與牆面機動；**幻影**打開遠中距射線與感測器，**鳴神**切開重甲與承重關節，**蛛絲**、爆破與電子戰建立支點與翻覆軸線。
* **破壞尺度**：
  * **普通戰鬥員**：乾淨主力踢擊即終止事件。
  * **頂級自然人與 S 級對手**：預讀、卸力與支點爭奪為核心，完整吃中後果嚴重。
  * **數百公斤級強化人與人形重裝**：可直接踢飛、升空、翻覆或砸入環境；幻影與鳴神縮短破甲時間。
  * **數噸級動力甲、輕中型載具與大型平台**：結合嵐足高輸出、高速路徑、下側軸線與蛛絲支點，可造成整體偏移、局部升空、翻覆與結構破壞。
  * **主戰級正面裝甲與戰略平台**：需結合鳴神、幻影、極限螺旋飛踢、弱點或跨隊資源。
* **後翻雙足上轟**：結合嵐足向上脈衝，臨床期壓縮成最短路徑，狂犬 binge 時則可能故意拉高浮空延長追擊；軍方會記錄足踝、膝髖與舊腹傷超限數據。
* **螺旋飛踢與人形飛彈衝擊**：以衝刺、蹬牆、蛛絲擺盪、嵐足彈射或高處墜落疊加初速，沿脊柱縱軸高速旋轉拉出冷藍螺旋尾跡，末端由目鏡標定集中貫穿。可貫穿超重型多層裝甲或翻覆數噸目標；代價為足踝麻木、跟腱與舊腹傷出血、嵐足過熱與背心能源見底，若遭軍方遠端斷電更會轉為直接反噬自身的慣性災難。

* **最初與技術裂縫**：白噪紀錄邏輯矛盾、檔案不自然刪節與自身身體記憶（「如果那個人真的只是檔案裡的陌生人，為什麼你們花這麼多資源阻止我知道他？」），促使她取得緒方系統部分審計紀錄，確認記憶被主動維持隔離，並在虛像遙測裡建立隱藏資料區，逐步推導執行環權限、武器簽章、能源與地理圍欄。
* **未立即逃亡的理由**：尚未能安全解除處決裝藥、隊友可能遭連坐、不確定找回記憶會留下什麼，且尚未建立離開基地後想去的地方。
* **監管假釋轉折**：憑藉煉獄坩堝後的戰功與制度信用、竹村的有限協助及銜尾蛇與軍方的協商，雪奈最終獲准基地外「監管假釋」，恢復銀色幽靈地下工作與私人生活（執行環、軍方強制勤務與虛像授權延續，認列任務繼續累積赦免點數；真正的記憶整合［雪人錄影留言］與點數赦免發生於後續假釋期，詳見《雪奈_監管假釋與復歸時期.md》）。
