# 1. 時期定位與核心事件

## 1.1 成熟五人送葬者與良性循環

士官學校滿分結業返隊後，經歷補員、傷亡與實戰磨合，送葬者定型為喪鐘最具代表性的五人王牌編制：

| 成員 | 職務與分工 | 與本期雪奈的協同 |
|---|---|---|
| **幽靈（朔夜雪奈）** | 隊長、全領域主攻與臨場指揮 | 不再事必躬親，學會精準派工、保留體力與抓決定性破口 |
| **釘子** | 副隊長、資深寡言狙擊手與戰術銜接核心 | 封鎖高威脅射線、掩護撤離、恐懼中仍保持功能；替雪奈兜底與控節奏 |
| **毒蛇** | 滲透、偵察、反制與側翼精準支援 | 提供視野、截斷退路與側襲配合；互嘴但信得過背後 |
| **龜甲** | 重裝、防禦支點、突破掩護與傷員後送 | 扛線與撤離核心；煉獄坩堝末段背負力竭的雪奈撤離 |
| **蜂刺** | 電子戰、無人機與情報支援（技術支點） | 與雪奈建立高度熟練的資訊協作，提供無人機視野、干擾與即時戰場情資 |

高難度任務的連勝帶來豐厚點數，徹底改善全員裝備、醫療與生活品質；隊友專業反過來降低雪奈的過度負荷，形成良性合作循環。在正規軍徵調的**綾瀨市戰役**等聯合作戰中，隊友親眼見識了雪奈原本就是全領域頂級殺手的恐怖實力，也真正理解她 38kg 身體的體力、傷勢與補給底線。

## 1.2 十萬點與「地獄裡的舒適」

* 王牌時期的任務點數遠超日常花費。雪奈把 B-17 從冷硬監禁室改造成應有盡有的私人小窩，大量添置甜食、漫畫、遊戲機、耳機、白噪音機、記憶膠體枕與絨毛玩偶；她甚至曾冒出「待在這個地獄裡，好像也過得挺舒服」的念頭。
* 她並未刻意存點數，卻成為喪鐘史上第一位把可用點數累積至**十萬點（特殊減刑申請門檻）**的人，迫使軍方重新檢視整套點數制度。
* **關鍵心態**：十萬點只是「減刑申請資格」，不等於最高級「天文數字正式赦免」，也不保證獲准假釋。更重要的是，此時的雪奈雖厭惡執行環與控制，卻因白噪隔絕了過去與歸屬，**還無法具體想像「離開基地後能去哪裡、要過什麼人生」**——當下最令她在意的仍是下一場帶勁的任務、送葬者這幫傢伙、收藏品與舒適的私人時間，尚未將減刑或逃亡當作人生目標。

## 1.3 煉獄坩堝（本階段高潮與分水嶺）

### 戰場崩壞條件
一場五重災難同時疊加的高烈度戰役：
1. 上級指揮鏈遭敵方斬首。
2. 戰區通訊大面積破碎。
3. 多支喪鐘作戰單位失去協同、各自陷圍。
4. 敵方重火力與環境災害重疊。
5. 原定撤離路線完全失效。

### 雪奈的八項戰術處置（尚無虛像）
她沒有選擇只靠個人戰力殺出一條血路逃生，而是：
1. 主動奪取殘存通訊節點。
2. 在殘缺資訊中重建完整敵我態勢圖。
3. 依各支喪鐘殘部剩餘的彈藥、傷勢與專長重新混編。
4. 讓狙擊、電子戰、輕傷員與突擊單位形成可移動火力網。
5. 果斷放棄保不住的重裝備以換取機動力。
6. 同時建立兩條假撤離線誘敵分兵。
7. 以自己作為高價值目標主動暴露、吸引敵方主火力。
8. 在最後撤離窗口把所有仍能行動的人全數帶離。

### 動機的模糊性與嘴硬台詞
她在通訊裡丟出來的全是冷硬尖銳的嫌棄：
* 「你們死光了，我還要自己搬彈藥。」
* 「不要讓我重畫路線。」
* 「能走的就走，不能走的開槍。」
* 「我只是不想聽你們在通訊裡一直叫。」

但她實際上沒有拋棄任何救得回來的傷員，為掩護最後一批撤離承受額外風險，甚至在原任務目標已可單獨完成後仍回頭重組殘部。這不能被簡化為「她突然善良」「眾人盲從最強者」或「她只是想殺更多敵人」，而是證明：

> 即使情感索引被切斷，她仍然本能地知道一個完整戰場不應只剩自己活著。

### 結局與後果
戰役末段，她耗盡全部可用體力、由**龜甲背負撤離**，昏沉之際仍以殘存意識持續協調喪鐘殘部收口。戰後倖存各隊主動提供證詞；已升任少佐的**竹村**以正規軍戰場觀察者身分向葛城提交關鍵戰報。軍方由此正式認定她具戰略級多隊指揮價值，破格授予特殊准尉、轉任「臨戰協調官」、搬入 404 號房，並由緒方博士於下一階段正式導入實驗平台「虛像」。

# 2. 外觀、服裝與 Type-W「Whiteout」

## 2.1 外觀與日常穿著

* 體能、氣色與營養全面恢復至巔峰水準；銀白長髮光澤回復，戰鬥時束高雙馬尾，基地休息時披散或隨手紮起。淡紫眼眸不再長期像初期般呆滯，日常懶散、打遊戲或吃甜點時活潑挑剔，交火時迅速轉成捕食般銳利。
* 頸部**執行環**始終在位（低亮度紅燈），成為日常舒適反差裡最刺眼的控制記號。
* **基地私人時間**：偏愛寬大舊 T 恤、運動短褲與隨手披的寬鬆夾克，徹底遠離初期討厭的緊身膠衣。

## 2.2 Type-W「Whiteout」個人訂製勤務服（王牌後段代表裝備）

王牌後段，雪奈以充裕點數與軍方配額取得個人訂製高階輕裝 **Type-W「Whiteout」**（非實驗性軍規裝備，與後期「虛像」分屬不同系統與用途）：

* **外層與上身**：白灰城市迷彩寬版衝鋒衣＋炭灰戰術衛衣＋輕量模組化胸掛。
* **下身與足部**：機能工裝短褲＋黑色高彈性機能緊身褲＋白色輕量護膝＋高幫強化戰術靴。
* **視覺與護目**：**琥珀色 HUD 風鏡**（提供基礎戰場標記、夜視與環境測距，非後期「虛像」高權限電子戰目鏡）。
* **雪奈的評價**：非常滿意白灰冷調配色、琥珀風鏡與毫無束縛的立體機動活動度，尤其高興終於可以少穿她極度厭惡的黑色緊身膠衣。
* **搭配武裝**：精良常規軍規槍械（依任務自選突擊步槍、衝鋒槍、狙擊槍或反器材步槍）、高品質軍用雙刃／戰術刀、軍規戰術纜索、爆破物與輕便電子滲透裝置。**不含幻影能量步槍、鳴神高頻軍刀、蛛絲三線匣與嵐足推進靴。**

# 3. 中期心理切面、生活質地與聲線矩陣

## 3.1 暴力耐受升級與基地日常並存

* **暴力成癮進入「耐受升級＋殘虐取樂」成熟期**：
  * 單純快速清掉普通雜兵已難帶來足夠清晰感；她開始更享受與強敵、重裝或高威脅目標正面交鋒，也會在安全餘裕下故意保留對手反抗能力、控制破壞順序，或用低聲笑與狂氣台詞（「起來。」「不要這麼快壞掉。」）索取恐懼回饋（詳見底盤 §3.2～§3.3）。
  * 同時，因為隊友在場、任務收口有明確目標，她多半能在關鍵時刻把失速衝動壓在任務與隊員安全線之內；釘子等老隊友也逐漸學會察覺她快要越過停止點的徵兆。
* **毒舌、玩心與具體在意回流**：
  * 記憶仍被白噪隔離，但她原本的性格色彩大幅復甦：在基地閒逛、去軍事模擬器刷誇張紀錄、找葛城鬥嘴嫌簡報囉嗦、替傷員順手帶東西或嘴硬探望，會因有人偷吃冰箱布丁或弄亂玩偶收藏大發脾氣。
  * 照顧本能的滲漏不再只有冷冰冰的「屍體擋路」，開始與自然的隊友默契、實務互助與尖銳玩笑並存。
  * 她不喜歡在日常生活中以隊長頭銜壓人，對其他小隊因嫉妒戰功與點數而欺負自己隊員的行為則相當護短。她會在休息期間去醫務室或士兵區探望、聊天，嘴上嫌麻煩，實際上關心他們的恢復、伙食、裝備與待遇。

# 4. 成熟部隊指揮與中期戰鬥尺度

## 4.1 成熟的部隊指揮（本期核心標誌）

士官學校歸來後的雪奈，正式從「把隊友當累贅的單兵」蛻變為「讓每個隊員變得更致命的隊長」：
* 懂得利用龜甲的正面扛線、釘子的狙擊封鎖與撤離掩護、毒蛇的側翼滲透與蜂刺的無人機／電子戰情報支援，不再把所有苦活硬攬到自己身上。
* 指令仍冷、短、少顧面子（「三組留兩人，不是留兩具屍體。」「東廊封死，傷員走維修井。」），但開始有意識讓隊友理解戰術意圖，令整支送葬者即使在她暫離火線時也能獨立運轉。
* 真正把「隊友活著回基地」排進任務代價考量——表面說是「重新磨合新人太麻煩」，實際上會為保住傷員重算整條撤離軸線。

## 4.2 中期戰鬥尺度（Whiteout＋常規精良武裝）

* 具備底盤 §4 完整全領域技藝、幽靈舞步、常規踢技六類語法與後翻雙足上轟。
* Whiteout 的高自由度剪裁與高幫強化戰術靴、護膝大幅改善了落地震衝與防擦傷能力，讓她在城市廢墟、室內狹道與多層建築間的立體折返更俐落。
* 對普通部隊、頂級自然人與數百公斤級強化人／重裝已具極高拆解與掀飛破壞力；面對主戰裝甲或超重型平台時，則靠精準導引送葬者全員火力、常規反器材狙擊、爆破弱點與結構破壞完成突破，而不是靠未導入的實驗推進器硬轟。

# 5. 人物關係與 B-17 軟裝日常

## 5.1 本期關鍵人物

* **葛城十藏**：已完全習慣幽靈的毒舌、任性與塞滿玩偶的房間；兩人常在會議室與辦公室鬥嘴，他對她逐漸生出長期相處下的熟悉與有限容忍（批准非違規私物與合理休整），但底層軍事控制與監視邏輯依然牢不可破。
* **送葬者成熟四人（釘子、毒蛇、龜甲、蜂刺）**：不再是只會服從最強者的附庸，而是各有脾氣、利益與底線的戰友。釘子成為她最信賴的副手與「判斷她何時該踩煞車」的觀察者；龜甲穩重可靠，敢在煉獄坩堝扛起脫力的隊長撤離；毒蛇與蜂刺則在日常鬥嘴、牌局、甜食爭奪與戰場死角補位中，讓世界重新出現「具體活著的人」。
* **其他喪鐘小隊（食屍鬼、繭等）**：原本視送葬者為雜牌強襲隊，隨王牌時期戰績與煉獄坩堝的跨隊救援，對「幽靈」轉為敬畏與複雜依賴。
* **竹村（少佐）**：天堂之門後晉升少佐，與雪奈保持有限的正規軍體系聯絡；在煉獄坩堝戰後提供的客觀觀察報告，是推動軍方重新評估她戰略價值的重要助力。

## 5.2 B-17 軟裝化與「柔軟堡壘」原型

此時的 B-17 仍屬監禁區單人房、監視依舊存在，卻已被雪奈用充裕點數改造成充滿生活氣息的小窩：
* 床上固定擺著縫補多次的小型「一號機」、巨型「二號機」與其他添置玩偶；另有記憶膠體枕、耳機、白噪音機、漫畫堆、手持遊戲機、小型甜食冷藏盒與簡易熱水設備。
* 她會認真研究新買的掌機與點數目錄、挑剔甜食品質、因遊戲卡關或同伴弄亂收藏而抱怨，也會趁休整泡熱水澡、聽音樂睡到自然醒。偶爾利用私物遮擋視線或藏筆記，但多數時候就是真心享受這些物品。

# 6. 中期專屬弱點、寫作提醒與一句話壓縮版

## 6.1 當期額外弱點（疊加底盤 §5）

* **缺乏離開的理由（「地獄舒適」陷阱）**：衣食無憂、有戰友、有刺激與收藏，使她暫時喪失對自由的迫切渴望，反而更深地嵌進喪鐘的成癮與制度循環裡。
* **團隊連坐槓桿浮現**：越開始在意送葬者成員能否活著回來，隊友就越容易成為軍方或敵方用來牽制她的籌碼。
* **裝備天花板**：Whiteout 屬高階輕裝，面對超重型軍規目標與重火力飽和覆蓋時，仍缺乏重裝護甲與實驗級機動推進，過度硬扛會直接耗盡體力（如煉獄坩堝末段力竭）。

## 6.2 寫作焦點提醒

* 本時期的獨有魅力在於**「殘酷戰場 × 熟練五人小隊默契 × 地獄裡的異常舒適」**的反差：她穿著最喜歡的 Whiteout 白灰衝鋒衣與琥珀風鏡、嘴上損著隊友卻替每個人留好活路，回到塞滿鯊魚玩偶和布丁的 B-17 打電動——直到煉獄坩堝把她推上更高的制度位置。
* **切記避開後期元素**：不可出現「虛像」五大模組、嵐足冷藍尾跡、緒方實驗測試、404 號房與准尉軍服。
