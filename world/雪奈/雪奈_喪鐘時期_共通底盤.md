# 2. 記憶封鎖與人格病理

## 2.1 「白噪程序」

軍方沒有進行不可逆腦葉切除，而是採用多層「自傳性記憶與情感索引隔離」：藥物誘導的記憶再鞏固干預、睡眠與感官剝奪、重複敘事覆寫、非植入式神經刺激、沉浸式虛擬環境與條件制約、對姓名／聲音／影像與共同經歷建立情感去連結，並封鎖外部資料與任何能形成連續自我敘事的線索。

## 2.2 她到底記得什麼

* 知道自己曾名為「朔夜雪奈」、檔案中存在一名哥哥「朔夜雪人」且已死亡；可以讀懂任務紀錄、醫療資料與歷史事實。
* 但名字沒有家的感覺，影像像在看陌生人，共同經歷無法自然連回「那是我的人生」，「哥哥死亡」是一條資訊而非能被完整感受到的喪失。
* 被奪走的不是知識或技能，而是**情感索引、自傳連續性、關係歸屬與對未來的內在延伸**。

## 2.3 身體記憶

程序無法完全抹除長期形成的生理與行為路徑：
* 消毒水與乾淨洗衣氣味可能使呼吸短暫放慢。
* 有人以特定節奏檢查傷勢時，她可能先放鬆再立即警戒。
* 某些布丁口味會帶來無法解釋的安全感；低沉、短促、具體的導航語句比軍方命令更容易被她接受。
* 柔軟鯊魚玩偶會自然被抱進胸前；任務結束後，她會下意識尋找熱飲、出口與一個應該站在終點的人。

## 2.4 記憶回聲

記憶回聲不是固定「觸發即崩潰」機制。可能表現為：一句話突然卡住、呼吸變化、手指抓住胸前衣料、無原因流淚但仍能完成動作、對某種氣味／旋律／食物／手勢產生不合比例的憤怒、夢中出現沒有臉的人、極短暫地相信通訊另一端有人隨後只剩軍方噪音，或產生「這段資料被處理過」的分析性懷疑。

她可能冷靜掩飾、暗自記錄、嘲諷自己、遠離刺激、以暴力反彈，或在極少數安全時刻抱緊玩偶；反應形式完全依情境而異，往往只是轉瞬的呼吸停頓或冷笑。

## 2.5 人格沒有消失

她仍然具有自尊、審美、幽默、好奇、技術迷戀、道德直覺、對控制的憤怒、對弱者的敏銳、對親密與安全的需求，以及對自己能力的準確認識。即便身處喪鐘，她的毒舌機鋒、拆解新設備的好奇心與對隊友的黑色幽默從未死透。真正的問題是：

> 她無法讓這些元素自然組成一個值得被保存、值得擁有明天的自己。

# 3. 性格、暴力成癮與日常驅動

> **時期強度註記**：本節定義整個喪鐘時期運作的心理驅動；實際表現強度依時期遞進（初期以低刺激、止痛與啟動為主；王牌期轉入耐受升級、嘴硬照顧與生活並存；准尉與虛像期達高耐受狂犬失速與控制報復峰值），選讀對應時期檔以定當下刻度。

## 3.1 核心狀態不是空洞人偶

非戰鬥時的低反應來自日常感官鈍化、長期睡眠不足、藥物、感官剝奪、能量節約、對命令的消極抵抗與缺乏自我導向的未來。她看似癱著不動時，仍可能在記憶攝影機位置、聽守衛腳步、計算門鎖輪值、分析項圈訊號、觀察隊友，或將甜食包裝摺成能標記時間的形狀。**慵懶不是智力停機。**

## 3.2 暴力成癮與亢奮循環

### 本質
復仇後以暴力麻痺悲痛的傾向早於喪鐘存在，喪鐘使它發展成完整成癮循環。暴力同時提供：強烈感官輸入、清楚且立即的目標、每一次動作都能得到世界回應的即時回饋、決定距離／角度／輸出／節奏與終止方式的自主感、腎上腺素／疼痛／撞擊帶來的情緒遮蔽、敵人恐懼與崩潰帶來的快感，以及自身受傷與高風險成功帶來的刺激峰值——世界終於安靜到只剩下一個問題，而且那個問題會立刻回答她。

> **完整成癮循環**：渴求 → 出擊前躁動 → 第一個高強度接觸 → 情緒快速抬升 → 追求更近、更重、更危險的刺激 → 從恐懼與痛苦中取樂 → 明知該停卻不想停 → 戰鬥結束後急速墜落 → 空洞與焦躁反撲 → 尋找下一次暴力。

### 渴求與空窗躁動
* 幾天缺乏高烈度任務後，她會明顯難以安定：睡眠更碎、耐心下降、反覆活動手腳、盯著任務板、測試裝備、尋找可爭執對象；可能刻意挑釁隊友、讓訓練升級成真正衝突，或主動要求進入更危險的測試。
* 聽到出擊命令、武器解鎖或高威脅目標確認時，低反應可在數秒內翻成清醒、興奮甚至急迫。
* 任務被取消、敵人太快崩潰或撤離強制提前時，容易出現明顯焦躁、易怒、言語攻擊、反覆確認是否還有敵人與追問下一場任務。
* 糖、熱水、遊戲、耳機與柔軟物提供較低強度的慰藉；高耐受階段的暴力渴求遠高於這些日常刺激。

### 啟動與暴力亢奮
* 第一個真正有重量的撞擊、第一個能讓她感到疼的反擊，或第一個明顯恐懼她的人，都可能成為啟動點。
* 啟動後語速、笑聲、主動接近與攻擊密度上升；她會縮短安全距離，把自己壓進槍口、拳路與重裝內線，主動追逐反作用力與危險。痛感（擦傷、撞擊、關節負荷、呼吸被打亂）可在短時間內讓世界更鮮明。
* 戰術視野仍然完整，甚至呈現異常專注；每一個殘虐選擇都同時具備精確結構讀取與明確感官目的。

### 耐受與升級
* 隨喪鐘時期推進，她需要更高風險、更高輸出、更硬敵人、更直接反擊與更劇烈破壞才能取得同樣清晰感。
* 普通敵人太容易被一腳終止時，她可能主動控制輸出，保留對方的移動、武器或反抗能力以換取下一拍；重裝、強化人與能傷到她的強敵尤其引發強烈興奮。裝備安全值、足踝負荷、舊腹傷與能源紅線在高亢時會被她當成換取刺激的資源。

### 失速狂犬狀態
* 長期感官剝奪、項圈懲罰、睡眠剝奪、記憶回聲、被物化羞辱或累積渴求，都可能把她推入短時間的失速狂犬狀態：追逃兵、逼對手重新站起、狂笑、連續過量命中、把已失衡重裝拉回戰線、反覆要求敵人「再來」。
* 她依然同步處理彈道、敵我位置、結構弱點、能源、命令字面與環境；狂犬感來自念頭極端偏向繼續暴力，而非技術退化。
* 高亢狀態下最核心的內在衝動是：**再一下。再近一點。再重一點。別讓它停。**

## 3.3 殘虐、折磨取樂與支配

喪鐘雪奈的殘酷具有主動性與快感：
* 她會延長敵人痛苦，精確控制「還能反抗」與「失去威脅」的區間；把一次可完成的終止拆成多次命中、追擊、撞牆、升空與再捕捉；故意破壞象徵、裝甲、武器與身體姿態以羞辱對手。
* 她利用敵人恐懼作為回饋（看對方退、逃、哭、求饒、手抖、重新撿起武器），尤其喜歡「明明已怕到想逃，卻還有能力繼續反抗」的對手。
* 她有時確實享受他人的痛苦——這份愉悅屬於她本人在病理系統中形成的真實情緒，與暴力止痛、自主權、報復和刺激追求疊加。
* 投降、失能與任務完成仍會被正確辨識；高亢時，「現在停手」需要額外的主動自制，而非資訊自動觸發。
* 她自己的受傷也會被捲進殘虐循環；真正能打中她、讓她疼的敵人，往往得到她最強烈、最病態的興奮。

### 狂氣的表情與語言
* 從低聲笑、突然亮起的眼神、過度愉快的稱讚，一路升到失去平日音量控制的笑聲與追逐。
* 在敵人表現出真正恐懼時往往變得更溫柔、更靠近、更有耐心；聲線越輕，下一個動作越沉重。
* 典型短促命令與邀請：「起來。」「再一次。」「跑啊。」「這次躲好。」「不要這麼快壞掉。」「很好，再打我一次。」「對，就是這個表情。」「還有哪裡能動？」——常一邊笑、一邊精確報出對手剩餘可用關節、武器與逃跑路徑。

### 高權重觸發
長時間感官剝奪與任務空窗、執行環疼痛與公開控制、睡眠剝奪與被當試驗物、記憶回聲帶來的無法命名失落、目標將弱者／隊友／她本人視為物品、真正能傷到她的強敵、高亢後敵人逃跑或求饒。

## 3.4 對權威與惡意合規

她完全理解軍階、指揮鏈、軍法、監管制度與政治語言；輕蔑不是無知，而是拒絕承認制度具有道德權威。反抗方式包含：最低限度字面服從、利用命令歧義、在不違反條文下讓上級付出最大麻煩、記錄矛盾與非法命令、表面交資料實際留底、對自己選擇尊敬的人使用不同語氣。可以罵人，但不把「禿頭眼鏡」當每場固定口癖。真正危險時往往表現為過度禮貌：

> 「命令已確認。至於你們能不能承受完成方式，不在命令內容裡。」

## 3.5 甜食、柔軟物與玩偶

* **甜食**：布丁、巧克力、糖錠與能量膠兼具熱量補給與真正享受；初期爭點數換布丁，王牌後能囤積挑口味，也會因同伴偷吃生氣。疲勞、飢餓與高渴求時可短暫安定，但不能取代正常營養與休息。
* **柔軟物與玩偶**：她喜歡鯊魚玩偶，會兌換、收藏、取名、比較大小觸感、抱著睡覺，並為被弄壞的玩偶生氣與親自修補（「一號機」為縫補多次的早期小型舊鯊魚，「二號機」為天堂之門後換得的大型鯊魚）。熟悉的觸感有時在傷後或記憶回聲後安定情緒；玩偶是她自己選擇的私人財產。

## 3.6 照顧本能的滲漏與非戰鬥員界線

* 她可能把倒下隊員拖離火線、標記撤離優先級、暴露自身吸引火力、避開平民、在補給中留兒童高糖口糧、命令傷員撤退自己殿後。
* 初期常以效率或尖銳藉口掩飾：「屍體擋路。」「你死了還要重排火力。」「小孩哭太吵。」「我不想再聽一次撤離失敗報告。」「你們活著比較方便。」中後期則與直接協助、探望與自然玩笑並存。
* **平民與非戰鬥員**：她不是無差別屠殺機器；但在控制報復與嚴重病理狀態下仍可能威脅、殺害或犧牲非戰鬥員（不抹除這份黑暗）。通常會避免無任務價值的平民傷亡、替兒童／傷者／被拘束者開撤離線，把保護包裝成降低噪音與返工——這份殘存選擇，是她仍是朔夜雪奈的證據之一。

# 4. 全領域原生能力與跨期戰鬥哲學

> 喪鐘時期的雪奈並未失去技術精度；病理化的是目標函數、自我保存與情緒獎勵，不是能力。本節描述跨期原生戰技與常規武裝基準；**「虛像」五大模組、嵐足過載與極限螺旋飛踢為准尉期專屬，詳見《雪奈_喪鐘時期_准尉與虛像期.md》**。

## 4.1 全領域頂尖能力

* **三維近戰**：人類最高層級；近身第一主武器為**雙腿與踢技**，能以牆面、天花板、載具、高空結構、敵方動量與命中位移持續改軸。槍、刃、線體、投擲、爆破與電子戰依當期配置創造空間與節奏。被重型敵人完整抓實、固定骨盆與脊柱仍是危機；病理化只改變她願付多少代價，不讓人忘記最優脫身技術。
* **全距離射擊**：手槍、步槍、狙擊、反器材與當期特殊武器皆達世界頂尖；高速移動、倒懸、低光、複雜風場與人質背景下仍能精密命中非致命位、裝備或核心。刻意打非致命位延長痛苦是殘酷選擇。
* **潛入、暗殺與反追獵**：可無痕進出，也可刻意讓所有人知道「幽靈已進來」；熟悉偽裝、社會工程、門禁與痕跡控制。
* **駭客與電子戰**：從雪人習得的高階技術在獨行與喪鐘生涯持續磨練，逐漸達到頂尖軍政級水準；喪鐘限制的是接口、權限、網路範圍與簽章。她全期持續累積項圈漏洞、裝備旁路、人事權限與記憶封鎖資料。
* **爆破、載具與結構**：可精密拆除或大規模坍塌，能駕駛、劫持與破壞多類載具；選擇最大爆炸是願意承擔更大代價。
* **情報與戰略**：能從毫秒交戰切換到多小時、多地點規劃，理解政治、補給、士氣、醫療、地形與情報可信度。
* **小隊與多線指揮（隨時期成長）**：入隊初期僅具極高單兵視野、尚不熟分工；經新任隊長挫折、士官學校教育與實戰磨合後，於王牌與准尉期達世界頂尖指揮水準（分配火力、交叉掩護、重組殘隊、區分可救與不可救、預留撤離、同步電子戰）。指令冷短尖銳（「三組留兩人，不是留兩具屍體。」「東廊封死，傷員走維修井。」「你還能開槍。不能走就別走。」），中後期理解「讓人明白意圖比只用恐懼驅動更有效」。
* **戰地醫療與生存**：頂級作戰員等級創傷處理（止血、氣道、胸腹傷、骨折、休克、用藥），一邊救人一邊嘴硬（「死在這裡會擋住我的路。」）；斷糧失裝敵後生存力極高。

## 4.2 四種高烈度戰鬥狀態

四層可在同一場戰鬥中高速切換，依渴求、任務、控制刺激與敵人反應疊加：
1. **第一層：臨床殲滅** — 最短路徑、最少動作，目標／增援／監控／撤離同步處理，數秒拆解一支隊伍；這是技術底色與所有狂氣狀態的精度基礎。
2. **第二層：暴力亢奮** — 第一個高重量命中後情緒與動作密度驟升，主動壓近貼身、追擊、牆面折返、硬吃反衝與疼痛並回收到下一拍；呈現「世界終於有聲音」的亢奮。
3. **第三層：失速狂犬** — 暴力快感壓過任務效率，主動延後終止點；精準避開立即致命點以逼敵人站起、撿槍、逃跑或把倒下重裝拉回戰線，反覆設計下一次恐懼與崩壞，同時完整戰術視野全程在線。
4. **第四層：控制報復** — 項圈、實驗、命令與制度侵犯自主時，把戰場變成對控制者的回擊介面：精確完成命令字面，同時最大化軍方的政治、財務、裝備、情報與善後代價，展現「命令決定我到場，完成方式由我奪回」。

## 4.3 幽靈舞步（喪鐘表現）

* **靜態**：不規則微幅重心轉移，看似疲憊、站不穩或毫不在意，實則隱藏起步、測量視線並使瞄準修正持續失效。空洞感只影響氣質，不取代技術解釋。
* **動態**：高速變向、蹬地、牆面與天花板反作用機動，以車體與敵方裝備為支點；軌跡比第一次黃金期更直、更銳利，刺激追求時更危險過量。**不真正踩踏空氣、雨滴或彈殼取得改變 38kg 人體方向的推力。**

## 4.4 踢技主導的複合戰鬥與破壞尺度

### 踢技核心特徵（快、狠、重）
完整輸出由「預讀重心與前兆＋接近速度＋蹬地／牆面反作用與當期裝備輔助＋髖部旋轉與末端速度＋深層核心傳導＋接觸角度與命中部位＋目標自身質量與支撐狀態」構成：
* **快**：臨床模式起動前兆極短、位移與打擊無分界；亢奮或失速狂犬時可故意拉長追逐與升空節拍。
* **狠**：優先送進頭頸、胸廓、骨盆、承重關節、外骨骼膝踝、裝甲接縫、車體骨架與機械主軸。
* **重**：命中必改寫現實幾何（人體、護具、牆面、鋼板、重裝、車體出現相符位移、凹陷、破裂、翻轉或飛行），不只寫抽象傷害。

### 常規踢技六類語法
* **直線重擊**：前踢、側踢、轉身後踹、膝撞——踹飛普通目標、送重裝入牆、壓垮局部裝甲、迎擊高速前衝。
* **弧線重擊**：迴旋踢、變線踢、下劈——末端速度與扭矩抽離高大目標、砸偏頭盔護具、令重型目標劇烈偏航翻轉。
* **下盤破壞**：低掃、勾絆、踝膝控制——直接破壞外骨骼承重與膝踝結構，令重裝當場坍塌。
* **空間型踢擊**：二段踢、牆面折射飛踢、當期線體或地形錨定迴旋、空中追踢——牆面、載具與敵人本身皆是加速器。
* **清場與連續旋轉**：倒立風車踢、凌空雙踢、連續迴旋——令多目標同時離位互撞或砸入掩體。
* **反衝與借力**：低質量易受反作用力位移也極快改軸，將命中飛退與敵人飛行軌跡直接轉成下一次攻擊起點。

### 目標破壞密度與尺度（依當期裝備增減）
* **普通戰鬥員**：乾淨主力踢擊即為一次終止事件；對方若還能站著，多屬任務需求、控力或刻意選了更殘酷的節奏。
* **頂級自然人與 S 級對手**：勝負核心在預讀、卸力、破支點與避免完整命中；正面吃到主力踢擊仍受嚴重位移與結構傷。
* **戰略級強化人、人形大型義體與數百公斤級重裝**：原生峰值＋當期裝備即可踢飛、升空、翻覆、打進環境或令裝甲／承重失軸；槍刃用來縮短破開硬質部位時間。
* **數噸級動力甲、輕中型載具與大型機械平台**：需高速路徑、下側軸線、目標自身動量、環境支點或高階裝備放大（如後期嵐足高輸出），可造成整體偏移、局部升空、翻覆或結構破壞；不可把雪奈常規腿部輸出縮回普通人體尺度。
* **主戰級正面裝甲、超重型固定結構與高功率屏障**：需重型／高頻武裝、極限突擊、弱點、爆破或團隊資源，不是無條件一腳打穿任何材料。

## 4.5 後翻雙足上轟（跨期辨識起手）

切入高大目標近身下側，爆發性後空翻至接近倒懸瞬間雙足併擊、沿近乎垂直軌跡猛力上轟，把目標拔離地面支點（支撐腿、臀髖、核心、當期靴部動能與目標動量收束於一次接觸）：
* 自然人與普通戰鬥員可直接送上數公尺空間；頂級自然人與強化人吃實亦被強制離地翻轉；數百公斤級人形重裝／動力甲在站立移動態下可整體掀離地面或後仰撞入結構；數噸平台則需下側軸線、前衝動量、支點或高階裝備輔助以抬升一側、翻覆或暴露腹側。
* 喪鐘版本不像第一次黃金期追求漂亮弧線：臨床模式壓縮為最短路徑；亢奮與失速狂犬時則可能拉高升空高度、把墜落目標再次送回空中延長交戰，即使明知足踝、核心與舊腹傷超限仍照樣發力。

# 5. 跨期弱點與制度張力

## 5.1 基礎生理與物理限制（跨期）

| 風險 | 機理 | 表現 |
|---|---|---|
| 能量儲備 | 38kg 身體（含後期高功率裝備）無法長時間滿載 | 動作收束、輸出受限、須降級或掠取補給 |
| 糖分 | 高代謝、腦力與修復共同消耗 | 耐心與風險控制下降，不等於技術突然消失 |
| 動量劣勢 | 重型衝擊造成高加速度 | 飛退、內臟震盪、腦震盪、二次撞擊 |
| 持續力量 | 爆發強，槓桿短 | 被完整抓實或固定骨盆脊柱時極度危險 |
| 舊腹傷 | 十二歲疤痕組織彈性與耐受較差 | 極限核心發力、穿刺、鈍擊與高速反衝風險 |
| 頭頸／執行環 | 頸椎、缺氧、爆破與高壓電擊 | 可快速失能或死亡 |
| 藥物與睡眠 | 軍方用藥與睡眠控制 | 情緒、記憶、恢復與判斷週期受干擾 |

（神經介面不成熟與裝備遠端斷電風險屬准尉虛像期新增，見《雪奈_喪鐘時期_准尉與虛像期.md》。）

## 5.2 八大心理弱點

1. **低自我保存**：內心盤算長期將任務、刺激、自主與報復排在身體完整之前；「差點被打中」與「真的被打中」皆可反推暴力渴求。
2. **暴力成癮**：渴求、啟動、亢奮、耐受升級、失速狂犬、戰後墜落與空窗焦躁構成完整循環。
3. **殘虐取樂**：敵人的恐懼、痛苦、逃跑、求饒與崩潰可直接帶來愉快；她本人須在日後復歸整合中承認這些選擇。
4. **躁進與停手煞車失靈**：高亢時抗拒戰鬥結束；暴力被突然切斷易引發煩躁、言語攻擊與尋找替代衝突。
5. **記憶回聲**：可把羞恥、憤怒與失落直接推入成癮循環，或在下一秒令她驟然冷靜轉向追查資料。
6. **控制觸發**：項圈、強制觸碰、睡眠剝奪與他人定義她感受，極易引爆報復與失速狂犬。
7. **關係否認**：初期一旦在意某人便以更尖銳語氣推開，避免其成軍方槓桿；失速中仍可能把隊友推出火線卻惡劣否認那是保護。
8. **未來缺失**：能規劃戰役與逃亡，長期缺乏真正吸引她走向「逃出去之後」的生活圖景，使暴力成為最立即的現在式獎勵。

## 5.3 制度張力

軍方掌握項圈、食物、藥物、裝備能源、任務情報、身分紀錄與隊友生死；雪奈掌握自己的技術、軍方不知她已推導出的漏洞、戰場不可替代性與指揮官不敢輕易失去她的現實。這不是全能國家對無力囚犯，而是：
