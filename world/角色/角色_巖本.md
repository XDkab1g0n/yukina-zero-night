# 巖本（Iwamoto）

## 核心身份
- 前代地下世界傳說級殺手「無冕之王」
- 現任「銜尾蛇」總教官
- 雪奈的養父與師父（實質）

## 外貌與氣質

| 項目 | 細節 |
|------|------|
| 年齡/體態 | 約60歲，體能外表維持40-50歲巔峰；178cm，精悍鋼鐵體格，無贅肉 |
| 面部 | 國字臉剛毅，灰白短髮＋修剪整齊鬍鬚；眼神內斂，平靜如古井，戰鬥時釋放壓迫感 |
| 著裝 | 黑色寬鬆練功服或唐裝（袖口捲起），布鞋或戰術靴；偶爾抽菸，散發滄桑危險氣場 |

## 性格與心理

- **外冷內熱的嚴師慈父**：表面沉默寡言、訓練時是「魔鬼」，實則對雪奈有深沉父愛；不輕易表露關心，以行動默默守護
- **極致自律與沉穩**：歷經無數殺戮後追求武道極致而非殺戮，氣質如山岳穩重
- **深藏愧疚**：對雪奈兄長之死及她坎坷的過去痛心；私下常自責她童年營養不足與過早承受高強度訓練可能影響發育（身高與胸圍）（隱藏老父親煩惱）

## 戰鬥風格：返璞歸真的宗師

| 特點 | 說明 |
|------|------|
| 全能型巔峰 | 精通格鬥、冷兵器、槍械，無短板 |
| 「不動如山」 | 與雪奈「極速」相反，以靜制動，最小動作化解並反擊；宛如不可撼動之壁 |
| 絕對預判 | 數十年生死搏殺經驗，透過肌肉微動預判行動；極少數能勉強跟上雪奈速度的人 |
| 一擊必殺穿透力 | 攻擊樸實無華（直拳、手刀），蘊含恐怖穿透力，可震碎內臟與骨骼 |

## 與雪奈的關係

- **實質父親**：雪奈童年道場與喪鐘復歸時期最重要的父親型依靠；從不言愛，行動處處庇護
- **最高敬畏對象**：雪奈對他抱有女兒對父親的敬愛；在他面前展現難得撒嬌與毒舌（吐槽訓練嚴苛、身材操心等）
- **實力變遷見證者**：喪兄前雪奈已站上頂尖水準，如今她在速度、裝備與全方位實戰上已明確超越師父，但巖本仍是極少數能跟上節奏、值得她認真切磋的前代宗師（師徒不設固定力量百分比）。他既欣慰（徒弟超越師父）又複雜（感慨成長代價）

十五歲後半年，銀色幽靈缺席引發的地下秩序危機中，巖本暫離教官生活重新出戰；雪奈復出後在他遇險時現身救援，並介入其後的大規模交鋒。詳見《../雪奈/雪奈_零式與第一次災難.md》。

在雪奈取得基地外監管假釋後，巖本與鬼婆佐藤安排她先指導成年殺手，再擔任一屆新人訓練營的首席教官。他看著曾經的關門弟子從喪鐘的殘酷中逐步找回教導與照顧別人的能力；奏正是在此時成為雪奈的學生。巖本仍是總教官與兩人的長輩，詳見監管假釋與復歸時期設定。

## 童年師徒關係的形成

巖本先在午餐考核中注意到九歲404號的天賦與傷勢，安排額外指導，約十歲收為關門弟子。道場共同生活期間，他親自照顧飲食、傷病及日常，亦教授文化課，發現雪奈的學習天賦。一次特訓意外後，雪奈從訓練筆記與雞湯理解他的心意，首次稱他「師父」。他替她慶生、爭取追加修行，十二歲贈無名雙匕送她出師。雪奈出師後仍回道場，師徒有真正的家庭生活與共同笑話。巖本擅長家常料理；他對雪奈的教育也在長期相處中逐步成熟。受佐藤提醒，他開始讓雪奈接觸武藝以外的生活，並為她保留日後另選人生的可能。即使她選擇以殺手為業，他仍把道場留作她的家。

## 角色功能

- **實力標竿**：前代最強，襯托雪奈「現任最強」的含金量
- **情感錨點**：雪奈與「普通人倫」的重要紐帶，見證並陪伴她走過修羅與喪鐘、重新找回生活與人性溫度
- **劇情推進器**：傳授新技能、提供關鍵情報、危機時出手的可靠長輩；「教官」身份可合理訓練奏等其他角色

## 一句話總結
> **巖本是實力深不可測、沉穩內斂、對雪奈懷有深切父愛與責任感的導師型配角——既是她過去殘酷訓練的象徵，也是如今心靈歸宿的一部分，在戰鬥、情感、劇情多層面支撐故事。**
