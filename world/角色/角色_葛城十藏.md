# 葛城十藏｜敲鐘人

> 喪鐘歷史角色，主要適用雪奈十六歲至十七歲監管假釋。制度見《../組織/組織_喪鐘.md》。

葛城十藏，約五十歲，喪鐘總指揮官與X-00的直接監管者，代號「敲鐘人」。老派軍官，眼鏡、整潔軍常服，重視紀律、結果及部隊資源。對官僚程序、失敗與失去控制易感煩躁；辦公室常有黑咖啡與應付工作壓力的常備藥品。

## 與雪奈的歷史

| 階段 | 態度與行動 |
|---|---|
| 初入喪鐘 | 將X-00按高危消耗品管理，對其個人需求缺乏特殊關心 |
| 單兵評估 | 由連續任務與檢查確認原生實力，改善醫療與營養，評估恢復後戰力；改稱「幽靈」 |
| 新任隊長 | 注意過度負荷及隊伍效能，安排指揮教育與重新帶隊 |
| 王牌時期 | 熟悉她的毒舌、任性及私人物品，允許更多生活待遇，重視穩定戰力與編制 |
| 准尉時期 | 信任指揮判斷，給予軍官職務及跨隊權限；仍保有監控與處置權 |
| 監管假釋 | 面對可在基地外獨立工作的戰略人才，參與制度安排；正式赦免後權力關係改變 |

他對雪奈的態度逐步軟化，既有長期接觸形成的熟悉與有限關心，也有對戰力的重視。兩人常鬥嘴：雪奈嫌會議冗長，葛城為她的違規、抱怨或過度消耗頭痛。她敢質疑他的命令及嘲笑他的外觀，他有時會責罵，有時也會批准她的私人需求。葛城的軍事利益與控制觀仍然存在，這段關係不等同於自由人的平等合作。

他理解雪奈的自然人身體及技術本身已有難以複製的價值，沒有以永久改造創造其能力。緒方博士在准尉後正式導入虛像。葛城與緒方的分工、白噪程序及執行環設定分見《../雪奈/雪奈_喪鐘時期_共通底盤.md》、《../雪奈/雪奈_喪鐘時期_初期至新任隊長.md》、《../雪奈/雪奈_喪鐘時期_王牌送葬者.md》與《../雪奈/雪奈_喪鐘時期_准尉與虛像期.md》。赦免前後具體立場與後續私人關係留待前傳。
