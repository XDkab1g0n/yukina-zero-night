# 送葬者｜喪鐘戰術小隊

> 歷史主管：喪鐘時期的小隊編制、成員與關係。制度見《組織_喪鐘.md》，雪奈個人底盤與階段分見《../雪奈/雪奈_喪鐘時期_共通底盤.md》、《../雪奈/雪奈_喪鐘時期_初期至新任隊長.md》、《../雪奈/雪奈_喪鐘時期_王牌送葬者.md》與《../雪奈/雪奈_喪鐘時期_准尉與虛像期.md》。

## 1. 定位與歷代編制

送葬者負責正面強襲、破障及重點突破。最初並非王牌；在雪奈帶隊、軍事教育、實戰磨合及裝備改善後才成為喪鐘代表性小隊。

| 階段 | 成員及變化 |
|---|---|
| 入隊測試 | 鐵砧、蟑螂、釘子、X-00；蟑螂未能留在後續編制 |
| 天堂之門前 | 鐵砧、壁壘、釘子、毒蛇、幽靈 |
| 天堂之門後 | 鐵砧、壁壘戰死；釘子讓位，幽靈成為隊長，補入獵犬與鬣蜥 |
| 新任隊長磨合 | 獵犬、鬣蜥戰死；雪奈負傷，後續補員 |
| 成熟王牌編制 | 幽靈、釘子、毒蛇、龜甲、蜂刺 |
| 軍官時期 | 幽靈卸任固定隊長，釘子接任；原成熟編制核心保留 |

軍校進修期間另有暫代指揮者，身份與任務細節未定。

## 2. 成熟編制

### 幽靈（朔夜雪奈）

隊長、全領域作戰。初期極度依賴個人實力；後來學會真正分配工作、欣賞不同專業並把隊員存活納入判斷。她仍有毒舌、殘酷、暴力渴求與任性的一面。升任准尉後轉任臨戰協調官。

### 釘子

資深寡言的狙擊手，副隊長，後接任隊長。早期阻止同伴的部分挑釁主要為紀律與任務；天堂之門後基於能力認可主動把隊長位置讓給幽靈。看過她因過度負荷重傷後，逐漸形成極為隱晦的保護欲，以實際支援、留意狀態及可靠執行表達，很少直接說出口。不是溫情外露的長輩。

### 毒蛇

偵察與滲透，較早期成員。親歷小隊從彼此不信任到成熟合作的過程，隨實戰與裝備改善成為可靠專業人員。具有自己的利益、脾氣及判斷。

### 龜甲

後期加入的重裝防禦與突破專家。煉獄坩堝末段曾背負已耗盡體力的幽靈協助撤離，使她仍能協調殘部。與嬌小高機動的雪奈形成戰鬥與體格上的對照。

### 蜂刺

後期加入的電子戰、無人機與情報支援人員。成熟送葬者的技術支點，與雪奈建立高度熟練的資訊協作。

## 3. 早期成員

鐵砧為初代隊長，曾輕視與敵視X-00，於天堂之門戰死。壁壘亦在同一任務戰死。蟑螂屬初期編制；獵犬、鬣蜥為新任隊長時期補員，對雪奈不服，後戰死。這些人屬不同階段，不會與成熟編制同時出現。

## 4. 共同生活與歷史

天堂之門、正規軍徵調（含綾瀨市戰役）與煉獄坩堝是重要共同歷史。戰功帶來點數及裝備改善，使隊員的專業能真正分擔幽靈的負荷。他們會競爭、抱怨、彼此利用，也會在熟悉後用實際行動表達信任。雪奈可在基地探望傷員、閒聊、鬥嘴或關心裝備。隊員仍是有各自人生與危險特質的個體。

Sigma的獨有角色（含火花）及同名人物不視為本小隊成員；其原始情節另見早期素材索引。
