# 巖本道場｜武術館與私人生活空間

巖本的私人道場及居住空間，也是雪奈約十至十二歲修行與共同生活的家。與銜尾蛇訓練設施有聯繫，具有保密性與相對獨立的生活環境；具體地址、地上地下配置、交通及平面未定。道場並非一般訓練生集體宿舍的一部分。

## 空間

| 區域 | 用途及生活質地 |
|---|---|
| 木地板道場 | 明亮寬敞、武器架、訓練器材，木頭、檀香及偶爾的菸草味；對練與教學 |
| 雪奈昔日和室 | 榻榻米、乾淨被褥、收納與私人用品；從最初不習慣軟床到能真正休息 |
| 巖本生活空間 | 書籍、茶具、個人器材與日常用品 |
| 浴室 | 可正常洗澡、整理儀容與休整 |
| 廚房及用餐區 | 家常料理、矮桌兼作文化課桌；曾因雪奈想做飯闖禍而修繕 |
| 緣廊與庭院 | 看雨、吃西瓜、休息、聊天、閱讀及戶外活動 |

## 歷史與使用

雪奈入營初期住受管制宿舍，約十歲收為關門弟子後才入住道場。巖本在這裡進行武藝修行及普通知識教育，也為她照料日常、慶祝十一歲生日；佐藤不時到訪。雪奈從此逐步擁有穩定生活、真正休息與家人的信任。

十二歲出師後雪奈搬往與雪人共同生活的安全屋，仍可回道場。十三歲生日與雪人、巖本、佐藤在此團聚。十八歲現在篇仍可作為探望師父、對練、吃飯、閒聊或回憶的家庭場所；雪奈不必在此維持任務中的姿態。具體是否保留原房間及現時改裝由故事確立。
